After forwarding a transaction document for Workflow approval, it is displayed in the Document Approval screen based on the employee hierarchy. The authorized person has to approve the records. A user can approve the request only when the workflow authorization is defined for his/her position.

Navigation path:

Click on the notification button, and then click on the approvals tab.

  • To process the document, navigate to the approvals screen by clicking on the approvals count as marked above.
  • To view the selected document, click the details button . The system will navigate to a query screen to check the details.
  • Select the appropriate radio button (Approve/Forward/Return) and click the Process button to perform the corresponding action.
  • Forward: The document can be forwarded to the next authorized person. Enter/Select the "Forward to" Person to process the document.
  • Return: The Document can be returned to the creator or the sender. Enter/Select the "Return to" Person (Creator / Sender) to process the document.
  • Wait: The Document can be moved to Wait Status by default for making no operation.
  • Approve: Select the Approve Radio button and press the Process button to approve the document.
