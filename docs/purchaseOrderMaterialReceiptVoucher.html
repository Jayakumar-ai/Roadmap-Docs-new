A Material Receipt Voucher is a document used to record the receipt of materials or goods into inventory. It details information such as the supplier, quantity received, condition of goods, and any relevant remarks. This voucher serves as a formal acknowledgment of the receipt of goods and is essential for maintaining accurate inventory records and facilitating seamless accounting processes within the ERP system.

Navigation path:

Supply Chain \ Inventory \ Transaction \ Material Receipt Voucher

  • Search screen displays the list of material receipt voucher with the relevant details and its status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On -click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on button to view the pending issuance to create the receipt voucher.
  • Click on create Receipt voucher button.
  • Screen Navigated to Pending Issuance.
  • Select the MIV document and Create Receipt button.
  • MRV document Created, the document Automatically navigates to Transaction screen.
  • Click on Post button to post the Material receipt voucher.
  • Accepted Stock is increased in Default warehouse of the Item.

Rejection warehouse Document

  • If rejection Qty exist in GRN, separate MRV document is created for the rejection warehouse.
  • Click on Post Button to post the Material receipt voucher.
  • Stock is increased in Rejection Warehouse of the Item for the rejected qty.

Accept on Deviation warehouse

  • If AOD Qty exist in GRN, separate MRV document is created for the AOD warehouse.
  • Click on Post Button to post the Material receipt voucher.
  • Stock is increased in AOD Warehouse of the Item for the rejected qty.
