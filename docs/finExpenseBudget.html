An expense budget is a financial plan that outlines expected expenses over a specific period, such as a month, quarter, or year. An expense budget typically includes categories like housing, utilities, groceries, transportation, entertainment, and other recurring expenses.

Expense Budget

  • Search screen displays the list ofExpense Budget with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new document.
  • Enter the Fin.Year.
  • Enter the Ref.
  • Click to save the header.
  • Clicking the Add button in the line section.
  • Enter the GL Acct details.
  • Enter CPC details.
  • Enter the Budget Amt.
  • Click to save, and the amount will be divided to all the months of the financial year.
  • Click on post and the document can be sent for approval.
