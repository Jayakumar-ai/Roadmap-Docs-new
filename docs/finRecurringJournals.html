Recurring journals are financial entries that repeat at regular intervals, like monthly or quarterly. They automate repetitive transactions, such as depreciation or rent expenses, ensuring consistency and saving time for accountants.

This screen is used to create Recurring Journals.

Navigation path:

Financials \ Transactions \ Journal Voucher \ Recur.Journal.

  • Recur. Journal Entry – for preparing manual recurring journal.
  • Post Recur.Journal – After creating the Journal entries, it can be posted using this screen.
  • Click on Recur.Journal Entry.
  • Search screen displays the list of Recurring Journals with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on the document to view the details.
  • Click on to create a new Recurring Journal.
  • Select the Loc ID.
  • Enter the Journal Amt.
  • Select the Start Date and End Date.
  • Select the Sou.vou.Pfx and other details will be displayed automatically.
  • Click to save the header.
  • Click on to create Debit details.
  • Select/Enter the Debt GL Acct.Desc.
  • Select/Enter the CPC Desc.
  • Enter the Share % (Note: it cannot be given more than 100%).
  • Click to save.
  • Click on to create Credit details.
  • Select/Enter the Credit GL Acct.Desc.
  • Select/Enter the CPC Desc.
  • Enter the Share % (Note: it cannot be given more than 100%).
  • Click to save.
  • Click on Generate and the Recurring Journal will be generated.
