A business function is an interface used to define master data, carry out day-to-day transactions, perform queries, and run reports within the system.

Navigation path:

Operating Instructions \ What is a Business Function

Business Function:

  • Used to define master data.
  • Used to carry out day-to-day transactions.
  • Used to perform queries.
  • Used to run reports.
  • Business functions are grouped based on their nature of use and functionalities.
  • For example, the Purchase Request business function comes under the Transactions section in the Purchase Order module.
