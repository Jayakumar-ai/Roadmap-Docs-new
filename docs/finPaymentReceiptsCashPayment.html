This screen is designed to streamline and facilitate the efficient handling of all pending transactions through Cash, ensuring that all financial records are up-to-date and accurately maintained.

Navigation path:

Financials \ Transactions \ Payment & Receipts

  • Search screen displays the list of Payment/Receipt Documents with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on the document to view the details.
  • View a Cash payment or receipts – enable only the Cash check box in the header.

Create Document from Pending Documents

The credit documents can be created for the below pending transactions:

  • Pending Payables.
  • Pending Payables – Advance.
  • Pending Payable – Statutory.
  • Pending Payable – Employees.
  • Pending Payable – Payroll.
  • Pending Payment advice.
  • Pending Payable – Bill discounting.
  • Click on Pending Payables to view the Pending Party document.
  • Fetch the document based on due days, party, currency, Amount.
  • Enter the Current Payable Amount and select the check box and click create.
  • Payment document can be created from this Page.
  • Cash payment can be done by selecting the cash.
  • User can make the cash payment for single document by selecting the Single option, or can merge the documents by choosing the Merge option.
  • Select the type as Bank.
  • Select the Cashier and click on Ok.
  • The payment document will be created as shown below.
