A work order is a document that specifies the tasks, resources, and instructions for performing maintenance work on a plant or equipment. A work order can be created for different types of maintenance work, such as preventive, corrective, predictive, or reactive.

Work requests and Maintenance Dues can be converted into work orders. Direct Work order can also be created by clicking the plus button.

Navigation path:

Plant Maintenance \ Transactions \ Work Order
