"Employee Loan Request" feature is designed to manage and streamline the process of requesting, approving, and managing employee loans

Navigation path:

Payroll \ Transaction \ Emp. Loan \ Employee Loan Request

Employee Loan Request

  • Search screen displays the list of Loan Request with the relevant details.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click, the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By clicking the Add button user can create a new document.
  • Enter Request Date.
  • Select Emp ID.
  • Select the Loan.
  • Enter the Reference.
  • In the Required details, enter the Loan Amount and date.
  • Select the Instl Ded. Mode and enter the necessary details.
  • If needed, add surety employees.
  • Click to save.
  • Click Post button and the document can be forwarded for approval.
