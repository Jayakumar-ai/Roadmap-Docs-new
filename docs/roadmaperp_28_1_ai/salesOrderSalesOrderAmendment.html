Sales Order Amendment

Sales orders are modified using the Sales Order amendment as explained below.

Navigation path:

Supply Chain \ Sales \ Transactions \ SO/CS Amendment

  • Search screen displays the list of Sales Order Amendment with the relevant details and its status
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On -click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click Cre SO/CS Amd button for sale order amendment
  • On clicking Cre. Sal. Ord. CS/Amd. Button, system displays the option select the Single Or Multi close short
  • On selecting the Multi close short button, multiple sales Order are close shorted simultaneously
  • Click button to create a new SO/CS Amendment
  • Select the Loc., unit is auto updated
  • Select the Customer and Click on Load Pending SO button, all the pending SO against the Customer are loaded in Lines
  • Select the Sales Order and click on Post button to close short the SO lines
  • On Selecting Single Close short radio button, Close short can be done sales Order wise
  • Enable the Update Close short flag to close short the Lines of the Sales Order
  • To modify the sales order by changing the Qty, Price, Disc% , Term changes & address details
  • On clicking post button, document is sent for Workflow approval.
  • To process the document in Workflow approval, navigate to approvals screen
  • To Click View details to view the selected document
  • Screen navigate into query screen to check the details
  • Now navigate back to the approval screen
  • Select the Approval/forward/Return radio button and click Process button to perform the corresponding Workflow process on the selected document
