"Travel Request" feature is designed to manage and streamline the process of requesting, approving, and managing Employee’s business travel.

Navigation path:

Payroll \ Transaction \ Business Trip \ Travel Request

Travel Request

  • Search screen displays the list of Travel Request with the relevant details.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click, the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By clicking the Add button user can create a new document.
  • Select Emp ID.
  • Enter Mobile Number and Email ID.
  • Enter Purpose of Travel.
  • Enter Departure Date and Return Date.
  • Enter Departure City and Designation City.
  • If necessary, mark the required check box and enter amount.
  • If necessary, enter ticket required and add the necessary details.
  • Click to save.
  • Click Post button and the document can be forwarded for approval.
