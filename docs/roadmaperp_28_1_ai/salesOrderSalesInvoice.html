Sales Invoice

A Sales Invoice is a document issued by a seller to a customer, indicating the products, quantities, and agreed prices for products or services the seller has provided. Here's an overview of how a Sales Invoice is created.

Navigation path:

Supply Chain \ Sales \ Transactions \ Sales Invoices

  • Search screen displays the list of Sales Invoice with the relevant details and its status
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new Sales Invoice by entering all the mandatory fields displayed in the Add dialog
  • Select the Loc ID, Unit is auto updated
  • Select the Type
  • Select the Customer and select the Currency
  • Click on button to create direct Sales Invoice document
  • On clicking button, Pending Sales Order & Customer Schedule yet to be processed is displayed as shown below.
  • Sales order and customer schedule are converted to sales invoice from the following screen
  • The Sales order created are displayed in the Pending SO tab of Pending Invoice
  • To create sale order from pending CS, click Pending CS radio button
  • Enter the Current Process qty and check the Select flag and click on the Create Sales Invoice button to create the Sales invoice.
  • Click Packing Slip button to print the packing slip details.
  • To view the selected records, click "Show my record" button.
  • For Direct Sales invoice, Select the item from LOV.
  • Enter the Invoice Quantity.
  • Enter the Price for the item.
  • The Disc % or the amount is entered. Based on the given input, the disc amount or the disc% will be calculated respectively.
  • Line Amount is calculated.
  • Enter the Tax set for the item if applicable.
  • Click on to save the Line item.
  • Allocate LS/Batch button shows the lot/serial details of the corresponding line item
  • Enter the Tax charge for the sales order.
  • Enter the Amount of the Tax charge if the level is selected as Value.
  • Enter the Assessable value for the Tax charge.
  • Enter the % for the tax charge if the level is selected as %.
  • Tax Charges can be added manually before include tax flag is checked.
  • To pick the quantity for packing list, press the pick button at header level.
  • To add the pending lines, user can click the "Add lines" button
Charges

This Screen is to add charges against the items such as Loading/Unloading Charges, to add the charges user must check the Inl.Chrg Flag, the charges will be automatically added to the Line amount, if the flag is not checked then the charges won't be added to the Line amount.

  • Click button
  • Select basis as either "%" or "Value"
  • Select Charge Item ID
  • Enter the percentage if the basis is selected as "%" or enter the value
  • Select the HSN Code
  • Click to save
  • Click cre. jrnl button to create the journal document
  • On clicking post button, document is sent for Workflow approval.
  • To process the document in Workflow approval, navigate to approvals screen
  • To Click View document to view the selected document
  • Screen navigate into query screen to check the details
  • Now navigate back to the approval screen
  • Select the Approval/forward/Return radio button and click Process button to perform the corresponding Workflow process on the selected document
