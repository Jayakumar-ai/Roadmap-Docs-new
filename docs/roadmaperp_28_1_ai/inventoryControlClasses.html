Classes are the categories or types of entities that are involved in the process of managing the inventory of a company. Classes can have attributes, which are the properties or characteristics of the entities, and methods, which are the actions or functions that the entities can perform. Classes can also have relationships with other classes, such as inheritance, association, aggregation, or composition.

This screen allows user to define the Classes and Class Types for the inventory items. User cannot change or remove a Class if it has any sub-classes associated with it.
