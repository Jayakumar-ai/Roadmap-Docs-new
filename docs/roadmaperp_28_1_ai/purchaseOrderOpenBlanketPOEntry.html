The Open/Blanket Purchase Order screen is used to establish the contracted price of items with a specific supplier. This feature allows for setting agreed-upon pricing terms and conditions for ongoing or future purchases, ensuring consistency and clarity in procurement transactions.

Navigation path:

Supply Chain Management \ Purchasing \ Transactions \ Open PO/RC

Figure 2.4.1

  • Open PO/RC is to create a new document
  • Open PO/RC Amendment option is to amend the blanket PO

Figure 2.4.2

  • Click on search button to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search button, system displays the results relevant to the search parameters entered.
  • On clicking; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the “” Add button we can create new Open Blanket Orders by entering all the mandatory fields displayed in the Add dialog
