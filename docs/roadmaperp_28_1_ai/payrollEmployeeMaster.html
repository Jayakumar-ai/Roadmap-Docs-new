Employee Master helps user to store all essential information about each employee, including personal details like name, address, contact information, job title, salary, tax details, bank account information, and any other relevant data needed to accurately calculate their payroll each pay period.

Navigation path:

Payroll \ Transaction \ Employee Master \ Employee Master

Employee Master:

  • Search screen displays the list of Employees with the relevant details.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click, the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click Migration button for bulk upload.

Employee Master:

  • Enter First name.
  • If required, enter the last name.
  • Select DOB & DOJ.
  • Select payroll calendar.
  • Select Zone.
  • Select Company Category & Account Category.
  • Select Payroll group.
  • Enter Notice period.
  • Enter Marital Status.
  • Click to save.

Salary:

  • Enter Designation, department and Grade.
  • Click to save.
  • Click Load allowance button and the allowances will be shown below.

Leave Detail:

  • Once Employee is in active state, leave details will be automatically allocated based on their designation.
  • Click on Post and document can be forwarded for approval.
