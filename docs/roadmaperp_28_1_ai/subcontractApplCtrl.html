  1. Unit

The Control of the Subcontract order management for the Unit is defined.

  1. Allow Direct SCO

The SCO can be created without creating the request.

  1. Inward Suplr. Bill required for SCO

Inward Suplr. Bill field of SCO document is mandatory for the gate document to get completed if the flag is checked.

  1. Price Opt.

The Subcontract Order Price Basis is defined based on the below types.

Item Wise: Price can be updated for the Subcontract order from the rate contract defined for the particular item.

Process Wise: If type is chosen as process wise, Price for the Subcontract order is fetched based on the rates defined for the process.

  1. SCO rejection Action

The Rejection action such as Debit memo / wait for action / No action for the SC rejection will works based on the list selected for the Primary and Secondary.

No Action – Rejection qty will not undergo any operations.

Wait For Action – Rejected quantity is waiting for the further processes.

Debit Memo – Debit memo will be created for the Primary and secondary SC rejection.

  1. Max. stk. Out days

If the material is issued to the supplier and if the DC exceeds the days given in Max Out days field, further transaction to supplier such as Material issuance, Subcontract Order creation will be restricted.

  1. Excess Material Return

The Excess material from the supplier can be returned based on the below types.

Before Receipt: The Excess material can be returned to the supplier before the GRN.

Before Invoicing: The Excess material can be returned to the supplier before the subcontract GRN is invoiced.

Before Mak. Payment: The Excess material can be returned to the supplier before making the payment for the subcontract GRN.
