This screen is used to create the sale order for the customer and the details of the sales are given in the sales order screen.

Navigation path

Supply Chain\ Sales \ Transactions\ Sales Order

Figure 2.23

  • If sale order and Customer Schedule are checked
  • Search screen displays the list of Sales Order and Customer schedule with the relevant details and its status
  • Click onsearch to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new Sales Order by entering all the mandatory fields displayed in the Add dialog

Figure 2.24

  • Enter the Loc ID, unit is auto populated
  • Select the Sales Order Type.
  • Enter/Select the Order No. prefix from the LOV.
  • Enter/Select the Customer from the LOV.
  • Enter/Select the currency for the customer from the LOV.
  • Click on button to create new sales Order

Figure 2.25

  • Enter/Select the Line item from the LOV.
  • Enter the Quantity and Price for the line item and HSN Code(If the sales price basis is User Defined else price of the Item will be automatically taken from the rate contract)
  • Other details of the item can be given by clicking the multi button
  • Enter the Disc% or Discountamount for the item, the disc amount or the Disc% will be auto calculated respectively.
  • The Ship To and Bill To fields are auto populated with the customer. If necessary, the field can be changed by selecting from the LOV.
  • Enter the Tax charge for the sales order.
  • Enter the Amount of the Tax charge if the level is selected as Value.
  • Enter the Assessable value for the Tax charge.
  • Enter the % for the tax charge if the level is selected as %.
  • The Tax charge can be deleted using Delete button.

Note: for price basis other than “User defined”, to populate the item in this screen, the Item Customer associate and saleable flag should be checked in the item master and Item unit association and accordingly it should be linked with customer item and the proper price basis screen.

If the flag is not checked, user needs to configure the price basis manually in the price basis screen.

Line Details

By Clicking the Details button to update the Sale order and the details of the Line items such as Discount [Cash, Trade, Special], and used to check the Item based class and subclass are fetched properly

Figure 2.26

  • Click to save the changes

Charges

This Screen is to add charges against the items such as Loading/Unloading Charges, to add the charges user must check the Inl.Chrg Flag, the charges will be automatically added to the Line amount, if the flag is not checked then the charges won’t be added to the Line amount.

Figure 2.27

  • Click button
  • Select basis as either “%” or “Value”
  • Select Charge Item ID
  • Enter the percentage if the basis is selected as “%” or enter the value
  • Select the HASN Code
  • Click to save

Figure 2.28

  • On clicking post button, document is sent for Workflow approval.
  • To process the document in Workflow approval, navigate to approvals screen
  • Click Viewdetailsⓘ to view the selected document
  • Screen navigate into query screen to check the details
  • Now navigate back to the approval screen
  • Select the Approval/forward/Return radio button and click Process button to perform the corresponding Workflow process on the selected document
