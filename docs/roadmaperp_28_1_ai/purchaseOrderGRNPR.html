The GRN PR screen is used for manual creation of purchase receipts. Details from purchase orders and gate entries are automatically generated and displayed in the GRN tab of the GRN Entry screen.

Navigation path:

Supply Chain \ Purchasing \ Transaction \ GRN - Purchase

Figure 2.17.8

  • Select the Unit location, Unit details will be auto updated
  • GRN Date is updated with sys date
  • Select the corresponding Prefixand Select the supplier from the LOV.
  • Enter Suplr Bill No & DC No
  • Click on button to create the GRN

Figure 2.17.9

  • Enter the Accepted quantity for the item; if quality is not enabled for the item.
  • If the item is defined as ‘Serial’, ‘Lot’in Item configuration, then Generate the lot serial No.
  • Lot/Serial details will be updated in Lot/Serial details dialog.
  • Accepted quantity can be edited, for the QC required “No” item and hence the Rejected quantity will be auto updated.
  • Excess Quantity supplied from the supplier will be updated in this field.
  • If the item is defined as ‘free pass’ then the status of the GRN will be updated as “QC completed”
  • If QC is defined as ‘always’ for the item else status is updated as “Draft”.
  • Warehouse can be modified, to store the item other than the default warehouse.
  • Cancel button is used to cancel the purchase receipt.
  • The Document will move on to the Pending PO screen if cancelled.
  • The Document will be sent for approval using the post button.
  • The necessary work flow operations are done in the Workflow document control screen
  • To approve the document, Navigate to the Workflow approvals screen
  • Click View detailsⓘFor specific document
  • Screen navigate into query screen to check the details
  • After click the back button document navigate into Approval screen
  • Choose the Approval/forward/Return button field and click Process button required process performed

Note: Sum of Accepted quantity and rejected quantity should not exceed the receipt quantity.
