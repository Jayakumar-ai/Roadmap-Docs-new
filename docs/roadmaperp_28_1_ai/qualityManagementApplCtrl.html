Entity

Figure1-1

  • Sample Source
    • System – Sample Document is created automatically.
    • Manual – Sample Document is created manually.
  • PDI Source
    • System – Pre dispatch inspection sample doc is created automatically.
    • Manual – Pre dispatch inspection sample doc is created manually.
  • FPI Receipt Type
    • Automatic–Final product Inspection doc is created and received automatically.
    • Manual – FPI Receipt type Document is created manually and received.
  • Var. Sample size
    • While inspecting the items with inspection document, the no. of samples to be tested for each characteristics and specification should be specified in this field.
  • Attr. Sample size
    • While inspecting the items with inspection document, the no. of samples to be tested for each characteristics and specification should be specified in this field.
  • No. of Var. Obs.
    • During inspection, the samples verified are marked with the observation values. The No. of observations should be captured in each sample while inspecting the items will be defined in the field.
  • No. ofAttr. Obs.
    • During inspection, the samples verified are marked with the observation values. The No. of observations should be captured in each sample while inspecting the items will be defined in the field
  • System Date wise Document Creation
    • If the flag is enabled, while creating Inspection document from pending Inspection Requests, Date dialog will not allowto edit the date of Inspection document creation and it is strictly adhered to create the quality document in the system date.
    • Else, the Inspection document will be created in the date as required by editing the date dialog.
  • Allow date wise document creation
    • If the flag is enabled, while creating Inspection document from Pending Inspection request, date wise document should be created.
  • Allow Upd. Rej. Qty based on Obs.
    • During inspection of items, if the observation values do not fall with the lower or upper limit defined, then the entire inspection quantities will be moved as rejected quantities. This happens automatically when the flag is enabled.
    • If disabled, the entire inspection quantities will not be moved to the rejection quantity bucket.
  • Auto create Inspection Document
    • Inspection Document should be auto created

Update

To make any changes in the setup, Click ”update” button and the Update screen opened

  • Click update button to make the changes and the screen will be redirected to the application control screen where user can see the old setup and the changes can be made in the new setup.
  • Make the necessary changes
  • Click to save
  • Click post button and the document will be forwarded for approval
  • To process the document in Workflow approval, navigate to approvals screen
  • Click View. Detailsⓘ to view the selected document which is inside multi button
  • Screen navigate into query screen to check the details
  • Now navigate back to the approval screen
  • Select the Approval/forward/Return/Wait radio button and click Process button to perform the corresponding Workflow process on the selected document.
  • Updated details are showing By Clicking the view update details

  • Click “” button to create
  • Select the Unit for which the control to be defined
  • Pur. Rwk. Creation

Rework process is initiated for the rejection quantities from purchase. Based on the selection, the document creation status is enabled.

  • Rwk. Ord.: Rework Order document is created
  • Pend Rwk. Ord.: Rework order gets approved automatically and displayed in pending rework order so as to create completion record
  • Rwk. Comp.: Rework order gets approved automatically and rework completion record itself gets created automatically
  • Prod. Rwk. Creation

Rework process is initiated for the rejection quantities from production. Based on the selection, the document creation status is enabled.

  • Rwk. Ord: Rework Order document is created
  • Pend Rwk. Ord.: Rework order gets approved automatically and displayed in pending rework order so as to create completion record
  • Rwk. Comp.: Rework order gets approved automatically and rework completion record itself gets created automatically.
  • Rework type
  • Based on the rework type chosen, the quantities subjected to rework will be scraped, disassembled or repaired.
  • Test certificate Type

During inspection completion, test certificate is created. It is of two types.

  • Test Certificate: Created Test certificate will be displayed in TQM1040
  • Machine Certificate: Created Test certificate will be displayed in TQM1036
  • Test Cert. Req. Type
    • Based on the types (Quality / GRN) selected, the test certificate provision is mapped. If the test certificate is required to be captured in GRN, the type should be selected as GRN, else if required in Inspection, the type should be defined as Quality.
  • Default Recommendation
  • Scrap While creating rework document, having scrap item
  • Rework While creating rework document, having rework process
  • Disassemble While creating rework document, having disassemble process
