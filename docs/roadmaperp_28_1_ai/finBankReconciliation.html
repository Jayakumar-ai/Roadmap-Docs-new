Bank reconciliation is a process that explains the difference between the bank balance shown in an organization’s bank statement, as supplied by the bank, and the corresponding amount shown in the organization's own accounting records at a particular point in time.

Navigation path:

Financials \ Transactions \ Payment & Receipts \ Bank Reconciliation

  • Enter/Select the Bank A/c from LOV.
  • Enter the As on Date and Save the Entry.
  • Document Number gets generated.
  • Click on Load Uncleared check box.
  • Issued/Received status documents are loaded when Load Uncleared checkbox is checked. Clear/Cancel/Void documents will not be present.
  • Click the line will display the query screen.
  • All the Issued status documents will be present in ADD:Cheque Issued But Not Yet Presented. Issued Status documents value will be summed up.
  • All the Received status documents will be present in Less: Cheque Deposited But Not cleared. Received Status documents value will be subtracted.
  • If any Issued amount to be added manually, the same should be added in ADD: credited in Bank statement But not considered in our book.
  • If Received amount to be less, it should be done in LESS: Debited in Bank Statement But Not considered in our book.
  • Click on Upd. Bank Book Balance check box will update the Bank book balance in header. Balance as per Pass Book value gets updated.
  • Finalize button will finalize the BRS.
  • PDF and Excel reports can be generated using Print BR(PDF) and Print BR (XLS).
