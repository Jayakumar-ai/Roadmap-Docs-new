A direct entry is a way of booking a bill without the reference of the GRN and without affecting the stock for a particular item. The matching type "GRN-Purchase (Without reference)".

The GRN which are received will be loaded in this screen; the invoice can be created from this Screen.

Navigation path:

Financials \ Transactions \ Party Document \ Purchase Bills

Registering Invoice

  • By Clicking the Add button we can create new document
  • Enter Sub Vou.Type as GRN-Purchase
  • Select Ref as W.O Ref.
  • Select Loc ID from LOV, Unit will be auto populated
  • Select Vou.Pfx
  • Select Party ID from LOV, Party name will be auto populated
  • Select Bill date and Enter Bill number

  • Invoice Receipt can be created directly in this screen.
  • Enter the Line items, enter the Quantity and unit cost and click to save the entry.
  • Document number gets generated.
  • After verify the value Click on Create Journal; Journal gets created.
  • Press the post button to complete the entry and the document will be moved to the workflow document control.
