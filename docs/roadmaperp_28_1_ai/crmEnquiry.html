An enquiry refers to a request for information or a question posed by a potential customer about your products or services.

In Enquiry screen, the customer or Lead can place an inquiry on new item or an existing item. If it is a new item, Feasibility and the cost estimation are done based on the Item placed.

Navigation path:

CRM \ Transaction \ Enquiry

  • Search screen displays the list of Enquiry with the relevant details and its status
  • Click on Search to filter all the records
  • User can filter the respective documents by entering the search parameters at the header
  • On clicking search button, system displays the results relevant to the search parameters entered
  • Using icon, entered search parameters can be cleared
  • To close the screen, use icon
  • On clicking Pending Leads button, leads yet to be processed to enquiry are displayed as shown below
  • Filter the Approved Leads with the relevant search fields in the header, leads will be displayed with the following details
  • Select the Lead and click on Create Enquiry button to create the enquiry

(Or)

  • By Clicking the Add button in the find screen, we can create new Enquiry
  • Choose the Doc. Pfx from the LOV
  • Enter the Date & Choose the Currency
  • Choose the Account
  • Enter the Enquiry Name
  • Select the Assigned Unit Loc., Assigned Unit is auto populated
  • Choose the Assigned To
  • Enter the Reference
  • Click on button to create direct Enquiry
  • Enquiry created is displayed as shown above
  • Select the type as Ex. Itm. or New. Choose the item and enter qty required
  • If it was new item Enter the item Description & Qty
  • Select the Feasibility and cost estimation required or not
  • If the FR flag is checked Feasibility study will be created for the enquiry
  • If the CR flag is checked Cost estimation will be created for the enquiry
  • Click on Post button to create the Enquiry
  • Select the cancel button to cancel the document
  • Click Print Button to view the Report
