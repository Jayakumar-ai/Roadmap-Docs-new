Open Subcontract Order screen is used to set the contract price of the Item to a particular supplier/Process.

Navigation path

Supply Chain \ Subcontracting \ Transaction\ Open SCO/RC

Figure 2.1

  • Search screen displays the list of Open SCO orders with the relevant details and its status
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the “ ” Add button we can create new Open SCO Orders by entering all the mandatory fields displayed in the Add dialog

Figure 2.2

  • Select Loc ID and Unit will be auto populated
  • Select Item from LOV
  • Select Supplier ID
  • Enter Eff. from Date and Eff.To Date
  • Click “” to create

Figure 2.3

  • Click to add the Process
  • Select Process from Lov
  • Enter Batch Qty
  • Enter Batch Cost
  • Click “” to Save
  • Click Post and the document can be forwarded for approval.
