This screen is used to clear any bank transactions. The status will be changed to clear query screen.

Navigation path:

Financials \ Transactions \ Payment & Receipts \ Bank Trans. Clear/Void

  • Query the voucher document.
  • Select the document using check box and click on Clear button.
  • Enter the date and click on Clear button.
  • Once the document is cleared, the same document will not get displayed.
  • Navigate to Bank transaction query screen (Bank payment or receipt) and query for the record. The status will get changed to Cleared.
