A major class is a way of grouping inventory items that share common features, such as type, size, color, material, etc.

User can use this screen to create a major class, which is a category of inventory items that have similar characteristics. Once user has created a major class, user cannot change or delete its description if it has any subcategories.

The user can only change or delete the description of a major class if it has no subcategories. The user can also view the list of all major classes and their subcategories on this screen.
