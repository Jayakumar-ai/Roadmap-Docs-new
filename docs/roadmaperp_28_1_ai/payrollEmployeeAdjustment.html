Any change made to an employee's pay, whether it's an increase or decrease, that is added to their regular paycheck to correct an error, account for a one-time event (like a bonus or reimbursement), or reflect a change in their base salary due to a promotion or other reason can be made using this screen.

Navigation path:

Employee Adjustment

  • Search screen displays the list of Employee adjustment with the relevant details.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click, the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By clicking the Add button user can create a new document.
  • Select Emp ID.
  • Add the line data.
  • Select the particular element.
  • Select the Start year and Period.
  • Enter the Total Period.
  • Enter the Amount.
  • Click to save.
  • Click Approved button for approval.
