In marketing Stage are all configured in this screen.

Navigation path:

CRM \ Setup \ Setup-Marketing \ Enquiry \ Stage

  • Click on button
  • Enter the Stage
  • Enter the Completion %
  • Enter the Seq. No.
  • Enter the Days
  • Select the appropriate Type
  • Select the Active flag if the Stage is to be used in transactions
  • Select the Default flag if the Stage is to be used in transactions
  • Click to save
