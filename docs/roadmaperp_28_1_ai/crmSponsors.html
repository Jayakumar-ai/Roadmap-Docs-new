Sponsors typically refer to individual sponsor who is responsible to set out the vision and goals of the CRM project in line with the overall company plans and strategy.

The details of the sponsors can be configured in the following screen.

Navigation path:

CRM \ Setup \ Setup-Marketing \ Campaign \ Sponsors

  • Click on button to create new Sponsors
  • Enter the Sponsor
  • Select the Active flag if the Sponsor are to be used in transactions
  • Click to save
  • Using icon to export the master data to Excel
  • Using Template button to download the template
  • Using icon to upload the master data
