To record the transaction and to trial balance chart of accounts needs to be created, which are posted in GL Account.

This screen used to create the GL groups and accounts.

Navigation path:

Financials \ Setup \ CPC/GL account \ GL Group/Accounts

  • Click to add GL Group.
  • Enter the group ID.
  • Enter/Select the group description.
  • Select the Acct. Group & Select the account type for the groups.
  • Enter/Select the parent group if the Acct. group is Sub and Save the Entry.
  • Account sub group into several types. Based on this, accounts will be displayed in LOV.
  • Click to save.

GL Accounts

This screen is used to create the account.

  • Click to add GL Account
  • Enter the Account ID and Account Description
  • Select the Group from LOV
  • All GL accounts can be displayed either as Active status or Inactive status or in New status.
  • By default active state account displays an Acct. type, PNL / BS, Customer and supplier. If want to do any changes, click required LOV and change it.
  • Click to save

GL Accounts Hierarchy

This screen is view the Hierarchy of the GL Accounts.

  • Double click on the GL Account and the option to edit/ add will be displayed.
  • Edit - the existing GL account can be edited accordingly.
  • Add Account - An account can be added inside the existing group.
  • Add peer Group - An peer group can be added inside of the already existing group.
  • Add Subgroup - An subgroup can be added under the existing group.
  • Mass Move - the list of accounts can be migrated from one group to another group using this option.
