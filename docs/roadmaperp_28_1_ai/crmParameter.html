Parameters are configurable options that adjust a component's behavior and appearance according to specific requirements or preferences without rebuilding the component, In marketing Group are all configured in this screen.

Navigation path:

CRM \ Setup \ Setup-Marketing \ Enq./Feas. Parameter \ Parameter

  • Click on button
  • Enter the Feasibility Parameter
  • Select the Group from LOV
  • Enable the flags if the parameters should be used on the process such as Enquiry, Quotation, Feasibility, New Job Meet, Cost Estimation
  • Select the Active flag if the parameters are to be used in transactions
  • Click to save
