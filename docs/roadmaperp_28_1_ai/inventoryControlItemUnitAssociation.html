This is the main setup for creating the Items. User can enter all the details of the Items / Products here and associate it with the units. User cannot change or delete an Item if it has any sub-items associated with it. However, user can edit the descriptions and details of the Items as needed.

Navigation path:

Supply Chain Management \ Inventory \ Setup \ Item – Unit Asso.

Figure 1.20

  • Search screen displays the list of Items associated with the Unit with the relevant details and its status
  • User can filter the respective documents by entering the search parameters at the header.
  • On Clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click “” button to create new Item Unit association

  • Click to save
