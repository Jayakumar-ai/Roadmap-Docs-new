The Purchase request converted from the RFQ/PO conversion screen is displayed in the Purchase Order Screen. The Purchase order can also be created directly in the purchase order screen based on the application control flag. The tax and shipment details of the PO are also included in this screen.

Navigation path:

Supply Chain \ Purchasing \ Transaction \ Purchase order

Figure 2.13.1

  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On -click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new Purchase Orders by entering all the mandatory fields displayed in the Add dialog
