An additional amount of money paid to an employee beyond their regular salary, usually given as a reward for exceptional performance, meeting specific targets, or as an incentive can be made using this screen.

Navigation path:

Payroll \ Transaction \ Payroll \ Employee bonus

Employee bonus

  • Search screen displays the list of Employee bonus with the relevant details.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click, the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By clicking the Add button user can create a new document.
  • Select the Calendar.
  • Enter Eff From.
  • Enter Eff To.
  • Select Type.
  • Enter the bonus, Exgratia, Incentive.
  • Select the Element.
  • Enter the Reference.
  • Click to save.

Calculation Element

  • Click to add the line.
  • Select the Element.
  • Select the Type.
  • Click to save.
  • Check Load Employee checkbox.
  • Click Post button and the document can be forwarded for approval.
