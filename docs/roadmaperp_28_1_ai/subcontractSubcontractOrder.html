  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.

  • The entire order or particular line can be cancelled by header using Cancel button or by line by pressing delete button in the Lines tab.

  • Click on Gen MRP button and Raw material requirement will be generated
