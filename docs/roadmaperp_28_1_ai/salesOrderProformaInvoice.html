Proforma Invoice

A Proforma Invoice of sale sent to customer in advance of a shipment or delivery of goods.

Navigation path:

Supply Chain \ Sales \ Transactions \ Proforma Invoice

  • Search screen displays the list of Proforma Invoice with the relevant details and its status
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On -click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new Proforma Invoice by entering all the mandatory fields displayed in the Add dialog
  • Click on button to view the approved sales Orders to convert into proforma invoices
  • Select the Loc ID., Unit is Auto updated.
  • Select the Proforma Invoice type.
  • Select the Doc Pfx.
  • Sys date is auto updated for the Doc. date
  • Select the customer from LOV
  • Currency is auto populated, if necessary user can change the Currency
  • Click to save the document header
  • Choose the Prof .pfx
  • Click to add the line details
  • Select the SO/Prj.Ref.
  • Select the Item.UOM & Item Desc. are auto updated
  • Enter the PI Qty.
  • Click to save the Line.
  • Click on Delete icon to cancel the lines
  • On clicking post button, document is sent for Workflow approval.
  • The Document can be cancelled by using the Cancel button.
  • Work Flow histories will be viewed using the View WF Hist. Provision.
  • Select the Print button to view the report.
  • To process the document in Workflow approval, navigate to approvals screen
  • To Click View document to view the selected document
  • Screen navigate into query screen to check the details
  • Now navigate back to the approval screen
  • Select the Approval/forward/Return radio button and click Process button to perform the corresponding Workflow process on the selected document
