User can use this screen to define the leave types and loan types.

Navigation path:

Payroll \ Setup \ Setup-Leave & Loan

Leave prefix

Leave:

Leave details can be defined in this screen.

  • Click to Create.
  • Enter the Leave ID.
  • Enter the Description.
  • Select the category.
  • Select week-off / holiday inclusion.
  • Select payroll elements.
  • Based on policy, enable the appropriate checkbox.
  • Click to save.

Credit Element

Employees who all are eligible for the leaves can be viewed in this screen.

Loan:

  • Click to Create.
  • Enter loan name.
  • Select From and To dates.
  • Select payroll element.
  • Enter minimum and maximum amount.
  • Enter installment period(in months).
  • Click to save.
