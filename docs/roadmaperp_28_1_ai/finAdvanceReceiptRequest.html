This Screen is used to raise the advance Receipt Document.

Navigation path:

Financials \ Transaction \Advance \ Advance Receipt

  • Clicking the Add button to create Advance Receipt Document.
  • Select the Location and Unit.
  • Select the Customer.
  • Select the Sales order.
  • Enter the Advance %.
  • Advance Amount will update based on Advance %.
  • Click post to complete the entry and the document can be forwarded for approval.
