Full and Final Settlement screen is designed to manage and streamline the process of settling all dues and payments for an employee who is leaving the organization.

Navigation path:

Payroll \ Transaction \ Resign & FFS \ Full And Final Settlement

Full and Final Settlement

  • Search screen displays the list of Employee Termination with the relevant details.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click, the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By clicking the Add button user can create a new document.

Bonus:

  • Select the Bonus Year, Period.
  • Enter the Earned amount.
  • Based on Transaction: Gratuity, Leave encashment, Imprest, Employee pay, Salary. Total Service benefits FNF will be fetched automatically.
  • Verify Additions and deductions.
  • Click Process Payroll button.
