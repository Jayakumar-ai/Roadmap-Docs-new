A pending quotation refers to a quote that has been created and sent to a potential customer but has not yet been accepted, rejected, or finalized. It is essentially in a waiting state, pending further action from the customer or internal approval processes.

In Pending Quotation screen if it was a new item, Item code request is created. If it was a new customer. Customer was created.

Navigation path:

Supply chain \ Transaction \ Sales \ Sales order

  • By selecting the record, Sales Order will be created
  • Based on the quotation types, Sales Order will be created
  • By Clicking Drop button to Drop the Quotation
  • Details button to click view the item details
  • Enter the Item ID.
  • Choose the Sub Class
  • Choose the UOM
  • Choose the warehouse
  • Click the Create item Code button
  • After clicking the Create Item Code Button , Item should be Auto created in Item Master with Filled Details
  • Click the Create Customer Button to covert the lead into new Customer before converting the quotation into order
  • Choose the Sub group
  • Enter the GST Number
  • Choose the GL Group
  • Enter the Credits limit
  • Click the Create Button
  • After clicking the Create Button, Customer should be Auto created in Customer Master with Filled Details
  • Select the Record
  • By Clicking Create SO Button, Sales order will be created
Note

After creating the Sales order, the Quotation cannot be revised.
