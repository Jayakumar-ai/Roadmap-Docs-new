GRN document created from Pending Gate Entry

The goods receipt note for the Purchase or Subcontract order can be created after passing through the Gate Entry. The gate document created will be displayed in the gate entry tab thereby GRN can be created by selecting the document and click on “Create GRN” button.

Figure 2.17.1

  • Search screen displays the list ofGRN with the relevant details and its status
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On -click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new GRN by entering all the mandatory fields displayed in the Add dialog
  • Click button to create the GRN from Pending Purchase Orders and Supplier schedule orders


Figure 2.17.2

  • Click Pending Purchase Orders button to create GRN from the posted gate entry documents. System navigates to the pending gate documents
  • Click Pending SuplrSchld button to create GRN from the approved supplier schedule Order. System navigates to the pending Supplier schedule Orders
  • Click Pending stock Trans. button to create GRN from the approved stock transfer purchase orders. System navigates to the pending Stock transfer purchase Order documents
  • Click Pending Gate entry button to create GRN from the posted gate entry documents. System navigates to the pending gate documents

Figure 2.17.3

  • Select the document and enter the GRN Date
  • Click on Create GRN button
  • Click ok
