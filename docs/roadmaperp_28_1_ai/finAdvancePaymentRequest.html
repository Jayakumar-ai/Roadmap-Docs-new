This Screen is used to raise the advance Payment Request.

Navigation path:

Financials \ Transaction \ Advance \ Advance Payment

  • Clicking the Add button to create the Request.
  • Select the Location ID.
  • Select the Party Type and Adv. Type.
  • Select the party
  • Select the Purchase Order for raise the Payment Request.
  • Enter the Narration.
  • Enter the Req. Adv. Pct.
  • Req. Adv. Amount should update based on Adv. %.
  • Press the post button to complete the entry and the document can be forwarded for approval.
