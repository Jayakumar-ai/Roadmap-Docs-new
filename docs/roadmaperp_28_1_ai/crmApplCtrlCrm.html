This screen is used to define the application control details of marketing management.

Navigation path:

CRM \ Setup \ Setup-Marketing \ Appl.ctrl.-Marketing

  • Click on Update button.
  • Click on button.
  • Cost Est. Cre. Type
    1. Manual - Cost estimation document is created manually.
    2. Automatic – If cost estimation flag is enabled for the Enquiry, while approving the enquiry, cost estimation is automatically created.
  • Define the overhead Basis calculation for the cost estimation based on
    1. Resource
    2. Percentage of Manpower
    3. Percentage of Material
    4. Percentage of Manpower and Material
  • If the Cost Estimation Reverse Rqrd. Flag is checked, system allows to reverse the posted cost estimation document
  • Enable the RM Cost Rqrd. Flag to include the RM cost for cost estimation
  • Feasibility. Cre. Type
    1. Manual - Feasibility study document is created manually.
    2. Automatic – If Feasibility study flag is enabled for the Enquiry, while approving the enquiry, Feasibility study is automatically created.
  • Click to save
  • Click Post to forward the document for approval
