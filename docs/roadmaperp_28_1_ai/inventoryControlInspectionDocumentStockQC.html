An inspection document is a record or report that documents the results of the quality inspections performed on items received into stock.

This screen is used to inspect the stocked Items.

Navigation path:

Quality Control \ Transaction \ Inspection Document

Figure 2.32

  • After posting the Inspection Request, Inspection document must be processed for the stock inspection.
  • Search screen displays the list of Inspection requests with the relevant details and its status
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Select the Inspection request and click on Create Inspection Doc. to create Inspection document from pending inspection request
