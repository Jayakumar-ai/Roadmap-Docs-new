Fixed asset expiration refers to the point at which a fixed asset, such as machinery, equipment, or vehicles, has reached the end of its useful life. This doesn't necessarily mean the asset is no longer functioning; it could be outdated, less efficient, or more expensive to maintain than it's worth.

This screen is to retire or terminate the Fixed Asset.

Navigation path:

Financials \ Transactions \ Fixed Assets \ FA Expiration

  • Search screen displays the list of Fixed Assets with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on the document to view the details.
  • Click on to create.
  • Select the Expiration Type.
  • Select Asset ID.
  • Enter the Termination date.
  • Click to Save.
  • Click on Run Depr. To run depreciation.
  • Click on Termination button to Retire or Terminate the Fixed Asset.
