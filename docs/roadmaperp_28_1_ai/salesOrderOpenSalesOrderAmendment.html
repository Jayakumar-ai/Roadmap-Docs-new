Figure 2.20

  • Search screen displays the list of Open Sales Order amendment with the relevant details and its status
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new Open Sales Order amendment by entering all the mandatory fields displayed in the Add dialog

Figure 2.21

  • SO amendment record is created from the approved rate contract
  • Enter Effective from and Effective To date
  • Line details are auto inserted with the Old price in Existing Price field
  • Enter the Revised Price
  • On clicking post button, document is sent for Workflow approval.
  • The necessary work flow operations are done in the Workflow document control screen (Refer: Workflow Management Doc).
  • Click on Cancel button document to cancel the SO amendment
  • Work Flow history will be viewed using the View WF Hist. Provision.
  • Select the Print button to view the report.

  • To Click Viewdetailsⓘ to view the selected document
  • Screen navigate into query screen to check the details
  • Now navigate back to the approval screen
