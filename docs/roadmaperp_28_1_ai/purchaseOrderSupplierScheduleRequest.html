The Supplier Schedule Request feature allows Business Units to request specific delivery schedules from suppliers. This functionality helps in aligning procurement with production or project timelines by specifying required delivery dates for goods or services.

Navigation path:

Supply Chain \ Purchasing \ Transaction \ Purchase Request

Figure 2.6.1

  • Search screen displays the list of supplier schedule requests with the relevant details and its status, If the SSR(Supplier Schedule Request) is checked.
  • Click on search button to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search button, system displays the results relevant to the search parameters entered.
  • On clicking; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the “” Add button we can create new supplier schedule request by selecting the option Create SSR.
  • Enter all the mandatory fields displayed in the Add dialog

  • Choose the Warehouse and Department name in LOV
  • Enter the Reference
  • To click button Document to create the supplier schedule request and navigated to the Transaction screen
