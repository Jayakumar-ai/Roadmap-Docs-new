An inspection is a process of examining products, materials, components, or processes to ensure they meet predefined standards, specifications, or requirements. This screen is used to create a new Inspection.

Navigation Path

Quality Management \ Transaction \ Measurement System Analysis \ Inspection

  • Search screen displays the list of inspection documents with relevant details and status.
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click the Add button to create a new Inspection document.
  • Select / Enter the Loc ID.
  • Select / Enter the Instrument.
  • Select Make.
  • Select Doc Pfx.
  • Select Doc Date.
  • Select Model.
  • Enter Certificate No.
  • Select the Location.
  • Enter Traceability and Reference.
  • Click on to create a new document.
  • Select the Model.
  • Select the Actual Insp. Date.
  • Select the Next Insp. Date.
  • Select the Inspector Name.
  • Select the Approver Name.
  • Click the button to add a new characteristic.
  • Select the Characteristics.
  • Select the Type.
  • Select the Specification.
  • Enter From, To, and Value.
  • Click on to save.
  • Click Post button to send the document for approval.
