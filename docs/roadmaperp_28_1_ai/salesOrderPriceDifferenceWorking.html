Figure 2.59

  • Search screen displays the list of Price Difference documents with the relevant details and its status
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On -click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new price difference by entering all the mandatory fields displayed in the Add dialog

Figure 2.60

  • Select the Loc id, Unit is auto updated
  • Select the Customer
  • Select the Date From and Date To
  • Enter the Reference
  • Click on button to create the new document

Figure 2.61

  • Click on Load button to load the invoice between the selected date from and To
  • Invoiced Price is updated for the invoices; enter the revised price for the invoice.
  • Revised Value of the Invoice is auto calculated.
