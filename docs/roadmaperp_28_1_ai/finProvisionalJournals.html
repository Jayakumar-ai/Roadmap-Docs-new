A provisional journal is a type of journal voucher that is used to record transactions that are tentative or uncertain and may be subject to change or reversal in the future. A provisional journal allows the user to enter the transactions in the accounting system without affecting the actual balances of the accounts. A provisional journal is also known as a draft journal, a temporary journal, or a suspense journal.

Provision means liabilities i.e. payable account. It’s very useful for controlling payable accounts like telephone charges etc.

This screen is used to post provisional journals.

Note

While creating Journal vouchers, Need to Check Provisional Journal Checkbox (as per the below steps) to create the provisional journal.

While creating a journal voucher

  • Select the unit, account, enter the debit and credit amount.
  • Need to Check Provisional Journal Checkbox.
  • After saving, click on post button for further approval.
  • Provisional entries can be viewed in the Balance sheet if Incl. Prov. Check box is checked.
