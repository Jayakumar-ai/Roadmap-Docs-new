During the Inspection transaction, rejection of quantities may occur. The root cause of the defect, its impact, and the necessary corrective actions to be taken for the defects related to the supplier or customer are recorded through the Eight Discipline (8-D) problem-solving process.

Navigation Path

Quality Management \ Transaction \ 8D (Eight Discipline Problem Solving)

  • Search screen displays the list of 8D documents with relevant details and their status.
  • User can filter documents by entering the search parameters in the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on Pending 8D documents to create 8D document from NCR documents.
  • Select the document and click on Create 8D Doc. button to create the 8-D document.
  • NCR document details and quantity information are automatically updated when creating the 8D document from pending NCR.
  • Click the Add button to create a team entry.
  • Select the team members involved in the eight discipline problem-solving process.
  • Choose the type (Team Leader, Team Member, Champion).
  • Select the employee from the LOV.
  • Enter the Email ID and Mobile Number.
  • Click on to save the team details.
  • Enter the Description of Defect.
  • Click the Add button under Interim Containment Actions.
  • Enter the Action and Effectiveness %.
  • Choose the Target Date and Actual Date.
  • Click on to save.
  • Click the Add button to enter root cause details.
  • Enter the Cause and Contribution %.
  • Click on to save.
  • Click the Add button to enter permanent corrective action.
  • Enter the Permanent Corrective Action.
  • Enter the Contribution %.
  • Click on to save.
  • Enter the Verification details.
  • Select the Verified By user.
  • Choose the Target Date and Actual Date.
  • Enter the system details involved in the 8D process.
  • Select the System Target Date and System Actual Date.
  • Enter the Problem Closure Description.
  • Select the Prepared By user from the LOV.
  • Select the Problem Closure Target Date and Actual Date.
  • Click on Post button to submit the 8D document for approval.
  • Click on Cancel button to cancel the 8D document.
  • Click on Print button to print the 8D document report.
