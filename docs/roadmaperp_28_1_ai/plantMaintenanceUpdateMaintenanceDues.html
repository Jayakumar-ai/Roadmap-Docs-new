Maintenance due in plant maintenance is the term used to describe the time when a plant or equipment needs to undergo a scheduled or preventive maintenance activity. This is done to avoid unexpected failures, improve efficiency, and reduce costs. Maintenance dues can be updated for the equipment of every department by providing the From and To Date

  • Click on Search to filter all the records
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
