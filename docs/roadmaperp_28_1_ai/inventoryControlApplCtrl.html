Application Control in Inventory control Management involves configuring the essential settings and parameters that govern the inventory process. This includes defining approval workflows, setting user permissions, and establishing business rules to ensure a streamlined, secure, and efficient inventory process.

  • Auto MR approve (MFG)

While creating the completion record in Production Order, MR will be created.

If the Flag is checked, the MR will be auto approved and displayed in ICM1020 i.e. ready for issuance creation

If Unchecked, the MR will be created and displayed as a new status record.

  • Auto MR approve (SC)

While creating the completion record in Subcontract Order, MR will be created

If the Flag is checked, the MR will be auto approved and displayed in ICM1020 i.e. ready for issuance creation

If Unchecked, the MR will be created and displayed as a new status record.

  • MR to PR

If the flag is checked, Purchase request is created automatically when the stock of the material is less to allocate for production. Else, purchase request should be created manually if material is devoid of stocks.Allow Partial issue

The Material issuance can be done partially if the flag is checked and vice versa.

  • Auto MR Allocation

After approving the Material Request, Materials are allocated automatically, if the flag is enabled

  • Auto MR Issue

MR created during the approval of SCO is approved, issued and DC will be created automatically when the flag is checked. Auto Issuance is done only when sufficient stock exist for the material. If stock is low, the record will be in ICM1020

If Unchecked, Only the New status MR will be created.

  • Auto Issuance Post

If enabled - After creating the material request, allocation of Material request is not required; hence the material issuance can be created directly and posted automatically.

If Disabled – Material request should be allocated and issued manually passing through subsequent screens.

  • Auto Issuance Post (Sales Return Stk. Trans.)

If enabled - After creating the material request, allocation of Material request is not required; hence the material issuance can be created directly and posted automatically.

If Disabled – Material request should be allocated and issued manually passing through subsequent screens.

  • Auto CMR Post

Customer Material Receipt document can be auto posted, if the flag is enabled.

  • Allow CMR Gate Entry

Gate entry document is created for the Customer Material receipt if the flag is enabled

  • Freeze Stock Trans

If the Flag is checked, the stock transaction will be suspended for the Freeze date given and no more transactions can be proceed further.

  • Allow backlog Entry

If the flag is checked, user can create the back dated entries

  • Auto Create PR/MR from Reorder

To create Purchase requests / Material requests based on the reorder Qty automatically, enable the flag

  • Weigh Bridge Required

If the flag is checked, Weigh Bridge value is mandatorily to be given.

  • Max Buyers allowed

The maximum number of buyers allowed to define in the users will be specified in the field provided.

  • Auto Creation MRV

Material Receipt voucher is created automatically when this flag is enabled during process completion

  • Auto Post MRV

To auto post the Material Receipt voucher, enable this Flag.
