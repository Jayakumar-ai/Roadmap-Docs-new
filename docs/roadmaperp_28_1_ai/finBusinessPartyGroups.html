The supplier group and sub-group are called us business party group are that are created using this screen.

Navigation path:

Setup \Business Party Groups

Party Group

  • Click to create a new Party group.
  • Enter the Group Description.
  • Check the active checkbox to use these groups
  • Click to save the group.

Party Sub Group

Supplier Subgroup can be created in this screen and the Subgroup can be linked with the Group.

  • Click to create a new Party Subgroup.
  • Enter the Sub Group Description.
  • Select the Group from LOV.
  • Select the Payment Terms from LOV.
  • Select the Ship Via
  • Select the INCO Term from LOV.
  • Enter the Allowed credit limit, if required.
  • Enter the GL Group for this sub group.
  • Click to save the entry.
  • Check Activate button to activate the party group.

Territories

This screen is used to create the territories.

  • Click to create a new Territory
  • Enter the Territory Description.
  • Select the Active checkbox to use the Territory.
  • Click to save the entry.
