If the gate entry flag is checked in the application control, the following documents are displayed in the Pending Inward screen corresponding unit in the respective Supplier schedule order or the Purchase Order tabs.

Navigation path:

Supply Chain /Gate Entry/ Transaction / Gate entry(Inward/Outward)

Figure 2.15.1

  • Search screen displays the list of Inward documents with the relevant details and its status
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On -click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new Gate entry inward by entering all the mandatory fields displayed in the Add dialog
  • Click on button and Select Pending PO, Page navigates into Pending PO

Figure 2.15.2

  • Select the PO Document and Click create Gate entry
  • Enter the Gate entry Date
  • Choose date and Gate keeper field
  • Enter vehicle No Details
  • Enter DC no and Inv no details
  • Give Reference and Driver Name details
  • Click OK button
  • Gate entry Document will be created

Figure 2.15.3

  • The approved supplier schedule orders are displayed in the Pending supplier schedule tab if the gate entry flag is enabled for the corresponding unit in the application control.
  • Click Pending Supplier Schedule Order and Page navigate into Pending SSO
  • Select the document and Create Gate entry
  • Gate entry Document Created and Document Navigate into Transaction Screen
