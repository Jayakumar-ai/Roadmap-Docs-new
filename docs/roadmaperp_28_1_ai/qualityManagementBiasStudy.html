A bias study in quality management, as part of Measurement System Analysis, is conducted to measure the difference between the average observed value from a measurement system and the true or reference value. This difference is referred to as "bias." This screen is used to view documents that are listed for Bias Study.

Navigation Path

Quality Management \ Transaction \ Measurement System Analysis \ Bias Study

  • Search screen displays the list of Bias Study documents with the relevant details and status.
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • To create a Bias Study document, go to pending screen in calibration and select the instrument.
  • Click on Create Calibration/Study Doc. button to create Bias Study document.
  • Select the Rqst. Dept. Name.
  • Select Calib. Rqst. Date.
  • Click OK.
  • Select the Model.
  • Select the Characteristics.
  • Enter the Total Tolerance, Level, and Process Std. Value.
  • Enter the No. of Readings.
  • Enter the Least Count.
  • Select the Actual Study Date.
  • Select the Next Study Date.
  • Enter the Confidence Level.
  • Click the button to add a new Reading.
  • Enter Level.
  • Enter Reading No.
  • Enter Observation Value.
  • Enter Bias.
  • If required, enter analysis details in the Analysis tab.
  • Click on to save.
  • Click Post button to post the document.
