This screen allows user to create an annual budget for each department.

  1. Department Budget – to create the department budget.
  2. Department Budget Revision - to revise the created budget.

Department Budget

  • Search screen displays the list of Budget with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new document.
  • Select the Fin.Year.
  • Select the Dept ID.
  • Click to save the header.
  • Click Add button to add the yearly budget in the Line.
  • Select Head Desc.
  • Enter Reference.
  • Enter Yrly Bud. Amt. , Based on the yearly amount, month wise amount will be calculate automatically.
  • The month wise amount can be edited, however if the overall amount is not summed upto the yearly budget amount, then exception will be raised as shown above.
  • The exception can be viewed by clicking the exception button.
  • Click Post button and the document can be forwarded for approval.

Department Budget Revision

  • Search screen displays the list of Budget with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new document.
  • Select the Dept. Desc. from LOV, in which the revision number will be displayed as shown below.
  • Select the Dept Desc from LOV, in which the revision number will be displayed as shown below.
  • When selected the Rev. No. will be updated.
  • Click the Add button.
  • Select the Head Desc., if it was defined already the type will be displayed as modify.
  • If newly created head, the type will be displayed as new.
  • Enter the New reference if required.
  • Enter the new budget amount.
  • If the defined budget to be removed, enter the new budget amount as 0.
  • Click to save.
  • Click on post button and the document can be sent for approval.
