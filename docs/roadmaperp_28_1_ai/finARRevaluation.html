Accounts receivable revaluation is a process used by businesses to update the value of their outstanding receivables in foreign currencies due to fluctuations in exchange rates. This ensures that the financial statements accurately reflect the current value of these receivables.

This screen is to update AP & AR Revaluation.

Navigation path:

Financials \ Transactions \ Revaluation \ AP/AR Revaluation

  • Search screen displays the list of AP\AR Revaluation with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Click on AR Revaluation option to filter only the AR Revaluation document.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on the document to view the details.
  • Click on to create a new.
  • Click on AR Revaluation option.
  • Select the Revaluation Date.
  • Enter the Narration.
  • Click to Save.
  • Click the Load Unit/Project button the Unit and Project is loaded as shown below.
  • Click the load button. All the party Document will be load till Revaluation date which can be viewed in Party Documents Tab.
  • All the documents are checked automatically.
  • User can uncheck the document as well. (If user wants to update the particular party or document or currency wise.)
  • Update the New Ex. Rate for each currency in the Exchange Rate Tab.
  • Click the Update button on the header. The new ex. Rate will be updated.
  • For each document associated with that party, if an adjustment is made on a future date, the offset details will be displayed in Offset document tab.
  • Click the Create Journal button to create the journal for AR Revaluation.
  • Click the View Journal to view the journal.
  • Click the Post button and the document will be posted.
  • After Posting the Revaluation, The Ex. Rate Details is updated in Source Document as shown below.
