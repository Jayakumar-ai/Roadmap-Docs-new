Purchase Request can be cancelled in new status from the Purchase request screen and in Entry Completed Status from the Workflow document control, if the user possesses authorization by pressing the Cancel Button. Status will be changed as ‘Cancelled’ and displayed in the view all tab and stocks will be updated for that item.

Navigation path:

Supply Chain \ Purchasing \ Transaction \ Purchase Request

Figure 2.9.7

  • Use Cancel button to cancel the document in transaction screen.
  • Status of the document will be updated as Cancelled.

Purchase Request Fetch

Purchase Request can be fetched with the help of Fetch Button. By Pressing Fetch ButtonFetch Item Dialog Box get opened. Class wise, Subclass wise and BOM wise details will be given manually and PressGenerate button.

Figure 2.9.8

  • Enter the required Quantity for each Item, and check Select Flag.
  • Check the Select all flag for Selecting all the items and Click OK Button.
  • Selected Items will be Auto populated in Lines screen.
  • Then Click the post Button for creating Purchase Request.
  • The Document will be sent for approval using the Entry completed button.
  • The necessary work flow operations are done in the Workflow document control screen
  • To approve the document, Navigate to the Workflow approvals screen
  • Click on View detailsⓘto view the specific document
  • Screen navigate into query screen to check the details
  • After click the close button document navigate into Approval screen
  • Choose the Approval/forward/Return button field and click Process button required process performed
