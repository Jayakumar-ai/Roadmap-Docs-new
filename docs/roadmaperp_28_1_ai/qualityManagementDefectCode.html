The defect codes can be defined in this screen. This screen is used to add, modify, and delete defect codes.

Navigation Path:

Quality Control \ Setup \ Setup - Quality

Add Defect Code:

  • Click the add icon to create a new Defect Code.
  • Enter the Defect Code Description.
  • Choose the Group.
  • Choose the Mach. QC Type.
  • Enable the required flags if the Defect Code should be used in processes such as PR, SC, SFC, CRM, QC, Stk.QC, and Pre.Disp. Fin.Insp.
  • Click to save.

Modify a Defect Code:

  • Only descriptions can be modified.
  • Click on the Defect Code.
  • Change the Description.
  • Click to save.

Disable a Defect Code:

  • Only unused Defect Codes can be disabled.
  • Select the Defect Code.
  • Disable the Active flag.
