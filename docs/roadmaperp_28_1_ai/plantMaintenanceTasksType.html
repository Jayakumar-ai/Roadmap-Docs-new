Task is a term that describes the classification of maintenance tasks based on their purpose, scope, or frequency. Task type can be based on the frequency, purpose, method, or trigger of the maintenance activity.

Task type can be defined and assigned to different types of task lists that describe a sequence of individual maintenance activities.

User can define the task type in this screen.
