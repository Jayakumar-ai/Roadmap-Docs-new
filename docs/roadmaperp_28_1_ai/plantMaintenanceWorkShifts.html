This screen allows user to set up the start time, end time and activate the work shifts. Work shifts are the time periods when the production processes are performed. User can create different work shifts based on the production needs and schedule. Shifts are typically scheduled to ensure that maintenance coverage is available 24/7.

The shift, start time, end time is defined in this screen.

Navigation path:

Plant Maintenance \ Setup \ Setup-Plant Maintenance \ Work Shifts

  • Click to Add.
  • Enter/Select the Unit Description
  • Enter the Shift Description
  • Enter the Start Time, End Time
  • Click on button to save
