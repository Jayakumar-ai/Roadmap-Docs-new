Item wise supplier details are configured in the Share of Business screen. This screen is used to Add, Edit and Cancel the Item and the Suppliers defined for the items.

Navigation path:

Supply Chain \ Purchasing \ Transaction \ Share of Business

Figure 2.1.1

  • Click on “” to Add New Document

Figure 2.1.2

  • Check the SOB flag in the Item master for the SOB Items.
  • Enter/Select the location for the Item.
  • Enter/Select the Item for which the suppliers are added.
  • Enter/Select SOB Pfx.
  • Enter the valid Date in the Effective From and Effective To fields.
  • Save the changes and Add the Document, the page navigate into Transaction screen
  • A unique document Number will be generated for SOB

Figure 2.1.3

  • Select the Type of suppliers for the item from the list item.
  • Enter/Select the Supplier from the LOV.
  • Specify the respective Unit
  • Enter the Percentage for Share of business.
  • Enter the Priority level for the supplier.
  • Save the Document
  • By using the Multi button, Cancel and Print options are present, the document can be cancelled or printed.
  • The Document will be sent for approval using the post button.

Figure 2.1.4

  • The necessary work flow operations are done in the Workflow document control screen.

Workflow history

User can use this button to view the forward, approval status of the document along with the date, user can also view the return status as well.
