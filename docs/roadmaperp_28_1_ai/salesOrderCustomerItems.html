The Customer Items of the master items are configured in this screen.

Navigation path

Supply Chain\ Sales \ Setup\ Customer Items

Figure 1.11 (Find page)

  • Search screen displays the list of Customer items with the relevant details and its status
  • Click onsearch button to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search button, system displays the results relevant to the search parameters entered.
  • On clicking; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.

Figure 1.12

  • All the approved customers are listed in the header
  • Choose the Item from LOV and map the item against the customer.
  • Assign the UOM, Price class, Price basis andHSNagainst customer.
  • Finally enable the Default flag.
  • Save the Customer Items

Price Basis

There are 5 types of price basis can be defined such as

1. User defined

2. Catalog

3. Standard

4. Open SO

5. Price list

Copy Customer Items

  • Press the Copy Button.
  • Choose the Customer and Click the OK button.
  • Choose the item
  • Click ok

Tolerance

  • Press the Tolerance Button.
  • Update From and To quantity and Tolerance percentage.
  • Save the changes.

Update Catalog

  • If the price basis is mentioned as catalog item, the update catalog button can be used to modify it
  • Save the changes accordingly.

Note: To populate the item in this screen, the Item Customer associate and saleable flag should be checked in the item master and Item unit association.
