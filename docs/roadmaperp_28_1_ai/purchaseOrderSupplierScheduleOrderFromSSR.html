Supplier Schedule Order (SSO) enables Business Units to convert approved Supplier Schedule Requests (SSR) into firm orders.

Navigation path:

Supply Chain \ Purchasing \ Transaction \ Purchase Order \ Supplier Schedule Order

Figure 2.7.1

  • Click button and Navigate into Pending Supplier schedule Request.
  • Select the option Pending SSR.

Figure 2.7.2

  • Filter the Required the Supplier Schedule Request Document.
  • Select the Supplier Schedule Request Document and Create SSO.
  • Choose the Supplier to click OK button and supplier schedule order created and navigate into Supplier schedule order document

Figure 2.7.3

  • Fetch the item in fetch open order field.
  • Click Generate the schedule and check the Schedule details generated and click post to post the document
  • Use cancel button to cancel the document
  • To approve the document, Navigate to the Workflow approvals screen
  • Click View details for specific document, Screen navigate into query screen to check the details
  • After click the close button document navigate into Approval screen
  • Choose the Approval/forward/Return button field and click Process button required process performed
