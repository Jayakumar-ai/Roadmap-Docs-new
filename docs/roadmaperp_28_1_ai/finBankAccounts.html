A bank account is a financial account with a banking institution, recording the financial transactions between the customer/Supplier and the bank.

This screen is used to configure the bank accounts.

The following types are available,

  1. Current / Loan
  2. Cash credit
  3. Savings
  4. Credit Card

This screen is used to create the Bank master.

Navigation path:

Setup \ Bank A/C

  • Search screen displays the list of Bank A/c with the relevant details
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On -click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new Bank A/c

Cheque Book

  • Enter the Cheque Book No.
  • Enter the No. of Leaves in the Cheque Book.
