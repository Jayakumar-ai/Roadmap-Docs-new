Once the Work Order document is posted, WO completion document is created as shown below.

Navigation path:

Plant Maintenance \ Transactions \ W.O. Task Completion

  • Search screen displays the list of Work Order completion records with the relevant details and its status
  • Click on Search to filter all the records.
  • Using Search, system displays the results relevant to the search parameters entered.
  • On -click, the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon
  • By Clicking the Add button we can create Work order Task Completion for the required Equipment. The details are populated to the transaction screen once executed.
  • Select the Loc ID, Unit is auto populated.
  • Select the completion basis.
  • Enter/Select Work Order no.
  • Enter W.O desc.
  • Enter the Requestor
  • Click on to create the new task completion record
  • Click the Load Cost Button to load the cost details such as Spare, Labor, external serv. cost
  • On clicking post button, document is sent for Workflow approval.
