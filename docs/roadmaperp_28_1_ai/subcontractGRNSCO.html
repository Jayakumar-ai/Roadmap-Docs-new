The GRN SCO screen is used for manual creation of receipts. Details from Subcontract Orders and gate entries are automatically generated and displayed in the GRN tab of the GRN Entry screen.

Navigation path

Supply Chain \ Subcontracting \ Transaction\ GRN-SCO

Figure 2.9

  • Search screen displays the list of Subcontract orders with the relevant details and its status
  • Click on search button to filter all the records.

Figure 2.10

  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on to view the pending subcontract orders without gate entry process.

Figure 2.11

  • Click on Pending Subcontract Order, system displays all the approved subcontract orders.
  • On selecting the Pending gate entry, user can view the approved subcontract orders processed through gate entry

Figure 2.12

  • Select the document
  • Click Create GRN Button

Figure 2.13

  • Enter the Supplier Bill No.
  • Enter the Dc No.
  • Click Ok, GRN SCO is created.
