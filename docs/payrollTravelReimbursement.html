"Travel Reimbursement" feature is designed to manage and streamline the process of reimbursing employees for their travel related expenses

Navigation path:

Payroll \ Transaction \ Business Trip \ Travel Reimbursement

Travel Reimbursement:

  • Search screen displays the list of Travel Reimbursement with the relevant details.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click, the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Enter Date from and Date to.
  • Enter City.
  • If required, add Additional Travelers.
  • Add Expenses by clicking Expenses button.
  • Click to save.
  • Click Post button and the document can be forwarded for approval.
