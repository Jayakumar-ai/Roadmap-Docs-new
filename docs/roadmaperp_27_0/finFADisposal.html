Asset disposal involves the systematic process of removing an asset from the company's records and recovering any remaining value. This can be achieved through various methods, including selling, scrapping, or moving to the stock.

This screen is used to dispose the Fixed Asset.

Navigation path:

Financials \ Transactions \ Fixed Assets \ FA Disposal

  • Search screen displays the list of Fixed Assets with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on the document to view the details.
  • Click on to create.
  • Select the doc date that must be less than or equal to asset expiration date.
  • Select Asset ID, other details such as Asset Desc, Sub group, group, department, location, sale value, asset value,net asset value will be updated accordingly.
  • Select Disposal type either as Scrap or Sale.
  • Click to Save.
  • Click on Run. Depr. to run the depreciation for the asset.
  • Click on Create Journal check box to create the journal and on view Journal button to view the Journal.
  • Click on Post to post the document.
