This screen is used to define Application journal Accounts for Finance.

Navigation path:

Financials \ Setup \ CPC/GL account \ Appl. acct.

Unit Wise:

This tab is used to set an unit wise application accounts.

  • Click to add.
  • Select Account from LOV.
  • Select Type which needs to be link in account.
  • Click to save.

Unit Wise Control Account:

This tab is used to set a unit wise control acct.

  • Click to add.
  • Enter/Select a trans. Unit from LOV.
  • Enter/Select angst. Unit from LOV.
  • Enter/Select an account from LOV.
  • Click to save.
