Application Control in Purchase Order Management involves configuring the essential settings and parameters that govern the purchase order process. This includes defining approval workflows, setting user permissions, and establishing business rules to ensure a streamlined, secure, and efficient procurement process.

Navigation path:

Supply Chain \ Purchasing \ Setup \ Setup-Purchase \ App.Ctrl - Purchase

  • Click button to create a new unit.
  • Select Unit from LOV.
  • Click “Ok”.
  • Select the created unit.

1. Unit

The Control of the Purchase order management for the Unit is defined.

2. Allow Direct PO

The Purchase order can be created without creating the Purchase request.

3. Allow Duplicate Suplr. Schld. Date Range

If the flag is enabled, System Allow to complete the Duplicate Supplier Schedule Document.

4. Hold PO for pending NCR

  • On Disabled Condition – If there is pending NCR documents for the suppliers for which a PO is created, a note alert will be thrown for indicating the pending NCR documents.
  • On Enabled Condition – The Field ‘Max. NCR doc. Allowed’ field is considered. If the pending NCR documents for the supplier for which a new PO is created, exceeds the max allowed doc, a stop alert will be thrown and the PO cannot be processed anymore.

5. NCR Type

NCR document can be calculated, based on following types.

  • Item Wise: NCR document will be generated based in the Item.
  • Supplier Wise: NCR document will be generated based on the Supplier.

6. Allow Gate Entry

The Document will be moved to Gate Entry after the Purchase order is approved. If unchecked, the document will be sent for Goods Receipt Note.

7. Inward DC required

Inward DC field is mandatory for the gate document to get completed if the flag is checked.

8. Inward Suplr. Bill required (PR)

Inward Suplr. Bill field of Purchase document is mandatory for the gate document to get completed if the flag is checked.

9. Auto Post Gate Entry

When the flag is enabled, Gate entry document is auto posted simultaneously while creating from Pending Inward.

10. Allow Direct GRN

The GRN can be created without creating the Purchase Order.

11. PO Closure

There are two types-Receipt Qty and Accept Qty.

  • Receipt Qty: If the purchase order quantity is rejected Partially/Wholly, the Purchase order can be created again for the Rejected quantity.
    PO Qty-100 Rejected Qty-50
    The New Purchase order can be created for the rejected quantity and the order is received.
  • Accept Qty: If the purchase order quantity is rejected Partially/Wholly, the rejected quantities are received against the same order.
    PO Qty-100 Rejected Qty-50
    The order will be in Open status until the PO of rejected 50 quantities is approved.

12. Purchase Acct. type

  • Net Purchase: If discount % is set for the purchase, the amount is deducted from the total amount and Journal will be created after deduction. But the deduction is not mentioned in the Journal.
  • Gross Purchase: If discount % is set for the purchase, the amount is deducted from the total amount and Journal will be created. A separate line will be displayed in the journal to indicate the discount deduction.
  • Check-Net Purchase
  • Un Check-Gross Purchase

13. AOD Warehouse Rqrd.

During inspection, the AOD (Accept on Deviation) quantities will be moved to AOD warehouse if the flag is checked, else the AOD quantities will be moved to the accepted store.

(Note: AOD Type of Warehouse should be configured in warehouse master CFG0191)

14. Allow Excess qty. Rcpt

If the PO quantity is received in excess, the excess qty in the order can be allowed/not allowed based on the flag enable/Disable conditions respectively.

  • Click “update” button to update the unit details or to enable the certain flags, which will open the below mentioned screen.
  • Select the Document, this will show the document changes to be made between old and new status.

Users can update, enable, or disable specific fields or flags in the Unit document. Additionally, this screen provides information about the user who created and updated the document, including the date and the approver's details.

  • Click (save) and “Post” the document and the Unit details will be updated accordingly.
