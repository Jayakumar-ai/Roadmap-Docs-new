This screen is used to define the application control details of Quality Management.

Navigation path:

Quality control \ Setup \ Setup-Quality

Entity:

  • Sample Source – System: Sample document is created automatically.
  • Sample Source – Manual: Sample document is created manually.
  • PDI Source – System: Pre-dispatch inspection sample document is created automatically.
  • PDI Source – Manual: Pre-dispatch inspection sample document is created manually.
  • FPI Receipt Type – Automatic: Final product inspection document is created and received automatically.
  • FPI Receipt Type – Manual: Final product inspection document is created manually and received.
  • Var. Sample Size – Number of samples to be tested for each characteristic and specification.
  • Attr. Sample Size – Number of samples to be tested for each characteristic and specification.
  • No. of Var. Obs. – Number of variable observations to be captured for each sample.
  • No. of Attr. Obs. – Number of attribute observations to be captured for each sample.
  • System Date Wise Document Creation – If enabled, inspection documents are created only on system date.
  • Allow Date Wise Document Creation – Enables creation of inspection documents date-wise.
  • Allow Upd. Rej. Qty Based on Obs. – Automatically moves quantities to rejection if observations fall outside limits.
  • Auto Create Inspection Document – Inspection document is created automatically.

Unit:

  • Click the add icon to create a new record.
  • Select the Unit for which the control is to be defined.
  • Purchase Rework Creation – Initiates rework for rejected purchase quantities.
  • Rework Order – Rework order document is created.
  • Pending Rework Order – Approved automatically and displayed for completion.
  • Rework Completion – Completion record is created automatically.
  • Production Rework Creation – Initiates rework for rejected production quantities.
  • Rework Type – Based on selection, quantities are scrapped, disassembled, or repaired.
  • Test Certificate Type – Test Certificate (TQM1040) or Machine Certificate (TQM1036).
  • Test Certificate Required Type – Quality or GRN based on requirement.
  • Default Recommendation – Scrap, Rework, or Disassemble during rework document creation.

NCR Type Configuration:

  • Define the NCR type configuration for the process.
  • Click button to create.
  • Select Unit from the LOV.
  • Select the NCR Type.
  • Select mode as Automatic or Manual.
  • Enable the Required flag.
  • Click to save.

Level Source:

  • Click the add icon to create.
  • Select the Unit.
  • Select the Inspection Type.
  • Select the Inspection Level.
  • Select the QC Prefix Level.
  • Select Allow Inspector Next Level flag.
  • Click to save.
