A GRN is used in the procurement process to verify and confirm the quantity and quality of goods delivered by cross-checking against a purchase order. It is sent along with the invoice, or bill.

The GRN which are received will be loaded in this screen; the invoice can be created from this Screen.

Navigation path:

Financials \ Transactions \ Party Document \ Purchase Bills

  • Search screen displays the list of  Party Documents(Purchase Bills)  with the relevant details and status.
  • Click on search to filter all the records.
  • Find In – Header and Line(s) option can be selected, if Header, the details of header will be displayed or Line details will be displayed.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new document.
  • By Clicking Pending Bills button, we can create the party document from pending GRN, Pending SCO, Pending PO, Pending ST and Pending LC.
  • Click on Pending GRN button.
  • search the Record by using the GRN No. and Records based on date.
  • Select the checkbox and click Create.
  • After completion of the Invoice Creation, we get the following updates:
    1. To be Invoice Quantity
    2. Invoiced Quantity
    3. In process Quantity

Updation:

While Invoice registration, Updates to the Details screen is explained as follows

E.g.:

Total GRN: 10 Qty.

Partial Invoice: 9 Qty selected in the details tab and the Invoice is created.

Initially, before invoice registration.

10 Qty will be in to be Invoice Qty.

0 will be in In progress Qty and 0 in Invoiced Qty.

After the invoice creation for 9 Qty.

updation:

  1. 9 qty will be increased in In-progress qty
  2. 1 qty will be in To be invoice qty
  3. 0 in Invoiced qty

After Invoice; Document gets approved.

In-Progress qty will be reduced and the quantity will be increased in invoiced qty.

In-progress qty will be 0.

Invoiced qty will be 9.

  • Select the Inv.Pfx and Inv Date.
  • Click Ok.
  • Invoices can be registered in this screen.

Registering Invoice

  • Purchase Bills created from pending bills GRN will be displayed in this screen with the Matching GRN-Purchase.
  • Get Doc. button is used to fetch a similar document lines from GRN-Purchase.
  • Click on Create Journal button to create the journal for the entry., and the deductions will be updated automatically, based on the party and Item configuration.
  • Click on create journal to view the journal/directly click post button, journal is created automatically and it will be posted.
  • According to the HSN code, the GST % will be fetched automatically.
  • If TDS Applicable checkbox is selected, then based on the TDS u/s the deduction will be applied.
Note

The Invoice quantity and the Unit cost can be modified if needed.

Invoice Quantity and Unit Cost Variance

We can able to change the Invoice Quantity and the Unit Cost in Supplier Documents.

  • Query the Record.
  • Change the Quantity or Unit Cost.
  • Save the changes.
  • Separate Journals will be created as Invoice variance for the deviation quantity or unit cost.

Project Due

The due amount of the project can be viewed in this tab.

Adjustment

If any advance has been paid, it can be adjusted in this screen.

Reference

  • If Exempt TDS check box is selected the TDS can be exempted for this document
  • If Allow IGST Tax checkbox is selected, then IGST can be entered for Local purchase
  • If Allow RCM Tax checkbox is selected, then RCM tax can be allow for Register Supplier
  • Click on to view the Bill amount details and address, if the Bill from Loc. is changed in header, it will be updated accordingly.
  • The round off details can also be updated by clicking the rounded off amount.

Round off Variance

  • The document amount can be rounded off, if needed.
  • Based upon the amount mentioned in the application control the round off amount can be accepted.
  • View Journal button consists of two buttons such as (a) Detailed journal can be viewed from Vw.Jrnl (Det) button and (b) the summary of the journal can be viewed from Vw. Jrnl (Sum) button. If the same account is found present twice, in the Vw.Jrnl (Sum) button, the amounts gets added up and the account is displayed once.
  • Click on Create Journal and the journal gets created.
  • Press the post button to complete the entry and the document will be moved to the workflow document control.
  • Delete button is used to delete the Record. Delete (L) button is used to delete the line records.
