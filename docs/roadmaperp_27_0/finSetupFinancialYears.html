A financial year is a 12-month period that is used for accounting and reporting purposes by different entities, such as governments, businesses, and organizations. A financial year can start on April and end on March of next year.

This screen is used to define Financial Years.

Navigation path:

Financials\ setup \ Fin. Year/ Periods \ Fin.Years.

This screen is used to create the Next Financial Year.

  • Press the Create Next Fin. Year/Period button to create next Financial Year.
  • Financial Year has been created message is displayed. Next Financial year will be created with the status as Not Started.
  • Click on the year to open/close or to update the Year End.
  • Status can be changed as open, closed based on financial period transaction.
  • If status need to be changed, all the period status should be in open or close on or previous or next year.
  • Close all periods button will close all the open period in that particular year.
  • Close Year button will display the open year as closed and it cannot be used for further transaction.
  • If Allow to Book Pervious Year AP Bill checkbox is enabled, then entries dated from that Closed year will be allowed.
