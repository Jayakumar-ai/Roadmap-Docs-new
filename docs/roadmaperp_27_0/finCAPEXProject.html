This screen is used to create CAPEX Project.

Navigation path:

Financials \ Transactions \ Fixed Assets \ CAPEX Project

  1. CAPEX Project – to create the CAPEX Project.
  2. CAPEX Project (Detailed) – to create the CAPEX Project.
  3. CAPEX Project Parameters – to mention the parameters of the CAPEX Projects.
  • Search screen displays the list of CAPEX Project with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on the document to view the details.
  • Click on to create a new CAPEX Project.
  • Select the Vou.Pfx.
  • Enter the CAP No.
  • select the Initiator ID, Name and Department Name will be displayed automatically.
  • Select the Proj. Nature,
  • Select the Supplier Details.
  • Enter the Start Date and End date.
  • If required, enter other mentioned details.
  • Enter the Ext. Expenditure.
  • Click to Save.
  • Click on Post and the document can be sent for approval.

CAPEX Project Parameter

This screen is used to create Parameters of CAPEX Project.

Checklist

  • Click on to create a new checklist.
  • Enter the Particulars and Remarks.
  • Select the option.
  • Enter the Print. Seq number.
  • Enable Active Checkbox.
  • Click to Save.

Justification

  • Click on to create a new justification.
  • Enter the Particulars and Remarks.
  • Enter the Print.Seq number.
  • Enable Active Checkbox.
  • Click to Save.

Monetary Benefits

  • Click on to create a new benefit.
  • Enter the description.
  • Enter the Amount.
  • Enter the Print.Seq number.
  • Enable Active Checkbox.
  • Click to Save.

Return on Investments

  • Click on to create a new ROI.
  • Enter the description.
  • Enter the Amount.
  • Enter the Print. Seq number.
  • Enable Active Checkbox.
  • Click to Save.
