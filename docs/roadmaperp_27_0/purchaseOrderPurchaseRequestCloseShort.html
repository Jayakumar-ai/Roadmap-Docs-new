The Purchase Request close short form allows you to close short the Approved and Partial Purchase Request lines. It is made possible only when the particular request lines were open and not yet have been converted into Purchase Orders. Once the request is close shorted or cancelled, the requested qty in the requested bucket will be decreased in stocks.

Navigation path:

Supply Chain \ Purchasing \ Transaction \ PR Close short

  • Search screen displays the list of Purchase Request close short documents with the relevant details and its status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On -click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new Purchase Request close short by entering all the mandatory fields displayed in the Add dialog.
  • Choose the Unit location LOV.
  • Choose the PR Document.
  • Text to enter the Reference value.
  • Click button to create the new document and control navigates to transaction screen.
  • Click Load PR to load the line details of the PR to be close shorted.
  • Click on Close short button, Document Close shorted.
  • The close short quantity will be updated in the PR lines.
