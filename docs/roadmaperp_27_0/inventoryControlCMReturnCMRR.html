A "Customer Material Return" refers to the process of a customer sending back goods they previously purchased to a company, which are then recorded in the system as a return

This screen is used to define the CM Return

Navigation path:

Supply Chain Management \ Inventory \ Transaction \ CM-Return (CMRR)

  • Search screen displays the list of CM Returns with the relevant details and its status
  • Click on Search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using Search, system displays the results relevant to the search parameters entered.
  • On -click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on Create CM-Return(CMR) button to create CMR from Pending documents
  • CMR Receipt (Rejection) – to create Rejection document from CMR receipt
  • Labor Order. Int-Reject (Prod.) – to create rejection document from production
  • Labor Order. Ont – Unprocessed (Prod.) – to create rejection document for unprocessed item in production.
  • Click on necessary option to create rejection document
  • Select the document and click on Create Rtn.Doc. button and the document will be created as shown below.
  • Click on Generate Cons. button and the consumption will be generated
  • Click on Post button and the document will be approved

(or)

  • Click button to create new CMRR by entering all the mandatory fields displayed in the Add dialog
  • Select Loc. ID
  • Select the Doc. Pfx.
  • Select/Enter the Customer
  • Enter the reference
  • Click and the screen will be navigated to create CMRR
  • Click button to create new line items
  • Select/Enter the Item
  • Enter the Rejected qty
  • Enter the other necessary details
  • Click to Save
  • Click Generate Cons. button to generate the consumption
  • Click on View. Exception button to view the exception details
  • Click on Post button and the document will be approved.
