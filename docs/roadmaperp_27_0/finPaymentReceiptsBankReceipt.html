This screen is designed to streamline and facilitate the efficient handling of all pending transactions, ensuring that all financial records are up-to-date and accurately maintained.

Navigation path:

Financials \ Transactions \ Payment & Receipts

  • Search screen displays the list of Payment/Receipt Documents with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on the document to view the details.
  • View a bank receipts – enable only the bank check box in the header.

Create document from pending documents

The credit documents can be created for the below pending transactions:

  1. Pending Receivable – Pending Party documents are listed.
  2. Pending Receivable – Advance – Pending advance documents are listed.
  • Click on Pending receivables to view the Pending Party document.
  • Fetch the document based on due days, party, currency, Amount.
  • Enter the Current receivable Amount and select the check box and click create.
  • Receipt document can be created from this Page. Bank receivables can be done by selecting the type as bank.
  • User can make the bank receipt for single document by selecting the Single option, or can merge the documents by choosing the Merge option.
  • Select the Pay mode.
  • Select the Bank and click on Ok.
  • The Receipt document will be created as shown below.
  • In the Lines, click on Add button to add the pending document for the selected party
  • Click on Pending party documents to create it against pending receivables.
  • Click on Pending receivables-Advance to create it against advance.
  • Select the necessary party document and Click on Ok and the document will be inserted.
  • In the Lines, click on View button to view the documents that are against the reference, wherein a new reference can also added here.
  • Click on to add receipt details for new reference
  • Enter the Bill/Doc.No.
  • Enter the Pay Amount
  • Select Dr/Cr.
  • Click to save
  • Click on Create Journal button and the Journal will be created.
  • View Journal button consists of two buttons such as (a) Detailed journal can be viewed from Vw.Jrnl (Det) button and (b) the summary of the journal can be viewed from Vw. Jrnl (Sum) button. If the same account is found present twice, in the Vw.Jrnl (Sum) button, the amounts gets added up and the account is displayed once.
  • Click on create journal to view the journal / directly click post button, journal is created automatically and it will be posted.
  • While approving the Receipt voucher document, the payment receipt document would be created automatically.

Against Receivable Advance

This screen is to enter the payment document as Advance against payment request.

  • Select the document and click Create.
  • Party can be selected line level and their Advance details will be present in Add. Button.
  • Click the add button to select the document.
  • After entering the amount, click on OK in add button will display the main screen.
  • Enter the Realized Amount and click on Update button.
  • Select the Create Journal check box and the journal gets created.
  • While, entry completing the document the document would go to the workflow document approval to approve the voucher to pay.
  • While approving the Receipt voucher document, the payment receipt document would be created automatically with the Adv. account type.
