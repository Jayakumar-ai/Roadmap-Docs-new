The Harmonized System of Nomenclature (HSN) code is an internationally accepted product coding system used for classifying goods under the Goods and Services Tax (GST) framework.

HSN codes are essential for businesses to ensure proper tax calculation, streamline GST filing, and maintain transparency in the tax system.

This screen is used to define the HSN code.

Navigation path:

Financials \ Setup \ GST/FA/Costing \ HSN Codes/Rates

HSN/SAC Code

  • Click to add.
  • Enter the Primary HSN/SAC Code.
  • Enter the Secondary HSN/SAC Code.
  • Enter the code type as HSN or SAC.
  • Enter HSN/SAC Desc.
  • Enter the Short Desc.
  • Enter the Input Type as Input, Input Service, Capital Goods, Ineligible.
  • Click on Active checkbox.
  • Click to save.

GST Rate

The GST rate for the HSN Code can be defined in this screen.

  • Click to add.
  • Select/Enter the HSN/SAC Code.
  • Enter IGST, CGST, UTGST, GST CESS percentage.
  • Enter the Date From and Date To.
  • Click on Active checkbox.
  • If it requires revision, click on the revise button.
  • If the GST rate needs to be deleted click on button.
  • Click to save.

RCM Category

  • Click to add.
  • Enter Category.
  • If it is a default category, enable Default checkbox.
  • Enable Active checkbox.
  • If the category needs to be deleted click on button.
  • Click to save.
