A Material Receipt Voucher is a document used in inventory management and accounting to record the receipt of materials or goods into a company’s inventory. It serves as proof that the materials have been received.

Navigation path:

Supply Chain Management \ Inventory \ Transaction \ Material Receipt voucher

  • Search screen displays the list of Material Receipt vouchers with the relevant details and its status
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • System displays the pending material issuance vouchers to be converted into receipt vouchers
  • Select the document and click on create Receipt
  • Material Receipt Voucher document is created as shown above
  • All the Line Items and issuance details are carried over to Material receipt voucher and now click on Post button to post the MRV document
