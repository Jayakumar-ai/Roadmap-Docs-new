Lot/Serial Expiry Updation refers to the process of updating and managing the expiration dates of inventory items that are tracked by lot or serial numbers

This screen is used to update Lot/Serial Expiry dates

Navigation path:

Supply Chain Management \ Inventory \ Transaction \ Lot/Serial Expiry Updation

  • Search screen displays the list of Lot/Serial Expiry Updation with the relevant details
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On -click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon
  • Click Add button we can create new Lot/Serial updation entry
  • Select the Loc ID
  • Click button to save the header
  • Click on Fetch button
  • Select the Item and Click Ok
  • Click on Update Expiry Button to update the New. Exp date
  • Select the Lot No
  • Select the new Expiry Date
  • Click Ok.
  • Click on Post to send the document for approval.
