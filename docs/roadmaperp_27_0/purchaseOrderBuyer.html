The Item to be purchased should be purchased by the designated buyer, whose details are configured in the following dialog. This configuration ensures that the correct individual is accountable for purchasing the items. Accurate buyer details help in maintaining proper records, streamlining the procurement process, and ensuring accountability.

Navigation path:

Supply Chain \ Purchasing \ Setup \ Setup-Purchase \ Buyer

Update a Buyer

  • Click "Update".
  • Choose the Employee from the LOV.
  • Enter the Effective From and Effective to date.
  • Click on "OK" button to save the employee.

Default Flag

When this flag is enabled the buyer details are set as default and will be shown in certain screen where buyer details should be mentioned.

Active Flag

This flag should be enabled to activate the buyer.
