"Employee Loan Payment" feature is designed to manage and streamline the process of repaying employee loans.

Navigation path:

Payroll \ Transaction \ Emp. Loan \ Employee Loan Payment

Employee Loan Payment

  • Search screen displays the list of Loan Payment with the relevant details.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click, the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
