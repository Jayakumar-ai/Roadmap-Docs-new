FA, or fixed asset, depreciation refers to the reduction in value of a tangible asset over time due to factors like wear and tear, obsolescence, or usage.

This screen is used to calculate FA depreciation.

Navigation path:

Financials \ Transactions \ Fixed Assets \ FA Depreciation

  1. Run Depreciation – to run the depreciation of a Fixed Asset.
  2. Depr. Journal – to creation depreciation Journal.
  3. Depr. Reversal – to reverse the depreciation.

RUN Depreciation

  • Search screen displays the list of Fixed Asset with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on the document to view the details.
  • Click on to create depreciation.
  • Select the Unit.
  • Click to create header.
  • Click on Post and the document will be posted.
