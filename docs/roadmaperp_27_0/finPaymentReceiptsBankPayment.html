The Payment & Receipts Screen in the ERP system serves as a crucial interface for managing financial transactions. It allows users to process payments and receive receipts for outstanding documents linked to suppliers and customers. This screen is designed to streamline and facilitate the efficient handling of all pending transactions, ensuring that all financial records are up-to-date and accurately maintained.

Navigation path:

Financials \ Transactions \ Payment & Receipts

  • Search screen displays the list of Payment/Receipt Documents with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on the document to view the details.
  • View a bank payment or receipts – enable only the bank check box in the header.
  • Click on Pending Cr.Docs.

Create Document from Pending Documents

The credit documents can be created for the below pending transactions:

  1. Pending Payables- Credit documents can be created against the payable.
  2. Pending Payables – Advance – document can be created against the payable advance.
  3. Pending Payable- Statutory – for all the TDS, ESI statutory pending document.
  4. Pending Payable – Employees – for all the Payment for employees.
  5. Pending Payable – Payroll - All the payroll Payment.
  6. Pending Payment advice - for all payment advices.
  7. Pending Payable - Bill discounting - The bill represents the total cost of all goods received but not yet paid for. It is issued with the expectation of immediate payment by the due date.

Bank Payment - Expenses

Expenses are the money spent or costs incurred by a business in an effort to generate revenue. Expenses represent the cost of doing business; they are the sum of all the activities that hopefully generate a profit.

This screen allows the buyer to pay the expense of a party by entering the details of the payment, such as the amount, the date, the bank details, and the invoice document number.

Navigation path:

Financials \ Transaction \ Payment & Receipts

Expenses

  • Vou. Date; by default it will display system date. If needed, user can change the date.
  • Select the Pay Mode. Enter the Favour of.
  • Enter the cheque date or select the date from date tool. Value Date will be auto populated as Cheque date.
  • Select the cheque no.
  • Enter/Select the Transaction currency.
  • Enter the Narration. Save the Entries.
  • Document number gets generated.
  • Select the Expense ledger in line level and enter the amount. For expenses account, reference details are not needed.
  • Select the Create Journal check box and the journal gets created.
  • While, entry completing the document the document would go to the workflow document approval to approve the voucher to pay.
