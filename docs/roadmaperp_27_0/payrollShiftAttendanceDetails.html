A breakdown of an employee's attendance information based on their assigned work shift, including details like clock-in and clock-out times, total hours worked during that shift, whether they were on time or late, and any potential overtime accrued. This allows accurate calculation of pay based on the employee’s specific work schedule.

Navigation path:

Shift Attendance Details:

  • Search screen displays the list of shifts with the relevant details.
  • Click Search to filter all the records.
  • User can filter documents by entering search parameters in the header.
  • Using search, system displays the results relevant to the entered parameters.
  • On click, the corresponding transaction record will be displayed.
  • Use to clear entered search parameters.
  • Use to close the screen.
  • By clicking the Add button, user can create a new document.

Shift Attendance Entry:

  • Select Unit and Department.
  • Enter reference.
  • Select type, year, and period.
  • Click to save.
  • Click to download the template.
  • Enter the necessary details.
  • Click to upload the template.
  • Enable the Check Exception checkbox.
  • Click to save.
