A department is a distinct functional area within an organization that operates with its own organizational structure. Typically, it has its own manager and an allocated operating budget. Departments can be categorized as cost centers, revenue centers, or investment centers. Examples of departments include accounting, production, and sales.

This screen is used to create a Department.

Navigation path:

Setup \ Departments

Group

  • Click button to create a new Dept. Group.
  • Enter the Dept. Group name and click on the Active checkbox.
  • Click to save.
  • User can use the upload option to add the multi-group at the same time.
  • User can also use download button to download the group in any preferred format.

Type

  • Click button to create a new Dept. Group.
  • Click to create a new Department Type.
  • Enter the Department Group name and click on the Active checkbox.
  • Click to save.

Departments

  • User can view all the created departments in this screen.
  • User can use upload button for the bulk upload.
  • Click to create a new department.
  • Enter Department ID.
  • Enter Department Name.
  • Select Department Type from LOV.
  • Select Department Group from LOV.
  • Select Loc. Name from LOV.
  • Enter Unit Name.
  • Enter the Address.
  • Click to save.
  • Click on the Active checkbox to activate a Department.
