The "Leave Encashment/Permission/Comp Off" screen typically refers to the functionalities related to managing employee leave and compensation.

Navigation path:

Payroll \ Transaction \ Attendance & Leave \ Leave/ Encash /Permission/ Com.Off

Leave

  • Search screen displays the list of Leave with the relevant details.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click, the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By clicking the Add button user can create a new document.
  • Enter Request date.
  • Select the employee.
  • Select Leave Type.
  • Select Start date.
  • Select Start session.
  • Enter the applied Days.
  • Enter the Reason.
  • Click to save.
  • Post the document and it can be forwarded for approval.
