A feasibility study is an assessment of the practicality of a proposed plan or project. It aims to determine whether the project/product is likely to succeed by evaluating various factors such as costs, benefits, risks, and potential issues, In marketing Feasibility Study are configured in this screen.

Navigation path:

CRM \ Transaction \ Feasibility Study

  • Search screen displays the list of Feasibility study with the relevant details and its status
  • Click on Search to filter all the records
  • User can filter the respective documents by entering the search parameters at the header
  • On clicking search button, system displays the results relevant to the search parameters entered
  • Using icon, entered search parameters can be cleared
  • To close the screen, use icon
  • On clicking pending Feasibility study yet to be processed is displayed as shown below
  • You filter with the Pending Feasibility. Field or with any of the relevant search fields in the header, pending feasibility will be displayed with the following details
  • Location, Account, Account type and item wise filter here
  • Select the Record
  • Enter the prefix & Click ok button to create Feasibility

(Or)

  • By Clicking the Add button we can create new Feasibility Study. The Feasibility study details given are populated to the transaction screen once executed
  • Choose the Loc ID
  • Choose the Account from the LOV
  • Enter the Require Date and completion Date
  • Choose the Doc Prefix
  • Enter the Reference
  • Click on
  • Enter the Account details (Either a Customer or lead)
  • Fetch the Department. The department involve in that production will be displayed
  • Enter the result weather it was feasible or not feasible
  • If it was Not-Feasible the Enquiry ends here
  • Enter/Choose the Feasibility Group from LOV
  • Enter/Choose the Parameter for Feasibility Group
  • Choose the Type
  • Click on Post button and the document can be forwarded for approval
  • If you want cancel the record, click the cancel button
Note

The document can be forwarded to other users to check the feasibility department wise and to update the status accordingly.
