This screen explains the steps required to log in to the Roadmap ERP application and access the system successfully.

Navigation path:

Operating Instructions \ How to Login

How to Login:

  • Launch and enter the Roadmap ERP URL.
  • The login screen will appear.
  • Enter the Username.
  • Enter the Password.
  • Click to login to the application.
  • On successful login, Roadmap ERP will be opened with pending notifications.

Application Tree Structure:

  • Click on the Tree icon to view the module structure.
  • The tree of each module contains the following sections:
  • Setup
  • Transaction
  • Reports
  • Analytics
