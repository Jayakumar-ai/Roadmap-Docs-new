A warehouse is a storage facility where inventory items are kept until they are needed for sale or distribution. A warehouse can be a building, a room, a container, or any other space that can hold inventory. It can also have different zones or sections for different types of inventory, such as raw materials, finished goods, or items in production.

Warehouse management involves various processes and tasks, such as:

  • Receiving goods
  • Storing goods
  • Picking goods
  • Packing goods
  • Shipping goods
  • Replenishing goods
  • Auditing goods

User can use this screen to define the Warehouse for the items. User cannot change or delete a Warehouse if it has any items linked to it. However, user can edit the Warehouse descriptions as needed.

Navigation path:

Supply Chain Management \ Inventory \ Setup \ Warehouse

  • Search screen displays the list of Warehouses with the relevant details
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click button to create a new Warehouse
  • Enter/Select Loc. ID; Unit and Address will be displayed automatically.
  • Enter Warehouse.
  • Enter Warehouse Description.
  • Select Type.
  • Select Supplier from LOV, if Type is selected as Supplier
  • Select Customer from LOV, if Type is selected as Customer.
  • Enter/Select Sales Area from LOV.
  • Check planning flag for considering the warehouse during MRP run.
  • Select saleable flag if the Warehouse is applicable for Sales.
  • Select Planning flag if the Warehouse is applicable for Planning.
  • Select Freeze Stk. Trans. Flag and enter the Freeze Date to prevent the transaction of the particular Warehouse from the date specified.
  • Select the Locator Tracker flag, if the Warehouse is included for Locator Tracer.
  • Select the Journal flag, if the warehouse is applicable for Journal creation for perpetual accounting
  • Click to save the Warehouse.

Locators:

  • Enter the Locator id and Description.
  • Enter /select the Locator Group From LOV.
  • After Enter the Group Description and UOM will be Automatically Displayed.
  • Enter the Max Qty for Locator Group.
  • Select the Locator Group Types ( Static, Buffer, Dynamic)
  • Static (only store single Item)
  • Dynamic (more than one item)
  • Buffer (we can store multiple Items with Unlimited Quantity)
  • Choose the Capacity Flag to declare the storage capacity of Locator.
