UOM is a term that is used to describe the physical unit (such as kg, dozen, meter, etc.) to measure and manage different items, User can use this screen to define the UOM (Unit of Measure). The UOM ID / code are fixed once user creates it and cannot be changed or deleted if it has any items linked to it. However, user can edit the descriptions of the UOMs as needed.

Navigation path:

Supply Chain Management \ Inventory \ Setup \ Setup - Inventory

  • Click button to create a new UOM
  • Enter the UOM (Units of Measurement).
  • Enter the Description.
  • Check the Fraction Flag if the UOM is handled in decimals
  • Select the type based on the UOM
  • Enter/Select the GST UOM.
  • Click to save the UOM.
