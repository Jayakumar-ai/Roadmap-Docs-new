This screen is used to create Parameters of CAPEX Sub Project

Navigation path:

Financials \ Transactions \ Fixed Assets \ CAPEX Sub Project

  • Search screen displays the list of CAPEX Sub Project with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on the document to view the details.
  • Click on to create a new CAPEX Sub Project.
  • Select Loc.ID.
  • Enter the Sub project Name.
  • Select the Parent Project ID.
  • Select GL Acct No.
  • Select Sub Group Desc.
  • Enter the Start date and End date.
  • Select Project In charge ID.
  • Click to Save.
  • Click on post and the document can be sent for approval.
