This screen is used to input employee hours, calculate their gross pay, deduct taxes and other withholdings, and generates the final paychecks for each employee, essentially completing the entire payroll cycle for a specific pay period.

Navigation path:

Payroll \ Transaction \ Payroll \ Prepare/Process Payroll

Prepare/Process Payroll

  • Search screen displays the list of Payroll with the relevant details.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click, the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By clicking the Add button user can create a new document.

Unit Group:

  • Select the calendar.
  • Select the year, period.
  • Enter Narration.
  • Click to save.
  • Check Load Unit Group checkbox.
  • Necessary Units and Group can be selected to run payroll.

Employee:

  • Check Load Employee checkbox.
  • Necessary Employees can be selected to run payroll.

Exception:

  • Check the prepare payroll checkbox.
