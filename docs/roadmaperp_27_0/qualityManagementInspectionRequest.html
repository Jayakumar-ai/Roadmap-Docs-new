Inspection request created from various sources are displayed as follows.

Navigation path:

Quality Management \ Transaction \ Inspection Request

Inspection Request – Search

  • Search screen displays the list of Inspection request with the relevant details and its status.
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using clear icon, entered search parameters can be cleared.
  • To close the screen, use close icon.
  • By clicking the Add button, we can create new Inspection request entry by entering all the mandatory fields displayed in the Add dialog.

Add Inspection Request

  • Inspection request can be created manually only for the Stock QC and Pre-Dispatch type.
  • For rest of the types, Inspection requests are created while processing the corresponding transactions.
  • Select Loc ID from LOV, Unit will be auto displayed.
  • Doc. Date is selected as current date, and can be changed if required.
  • Select the Doc. Pfx.
  • Select the W/H.
  • Select the Inspector.
  • Click to save the header and the screen will be navigated.

Inspection Request – Processing

  • Inspection Type will be appropriately displayed for which the request has been created.
  • The Lot serial details of the items will be viewed in the Lot / Serial dialog.
  • In case of Subcontract and production completions, the process for which the request is being created will be viewed.
  • Click on Post and the document will be posted.
