A debit note issue is a document that is issued by a buyer to a seller when the buyer owes the seller money. A debit note issue can be used to request a payment, to charge a penalty, to increase an order, or to reduce a credit. A debit note issue can also be called a debit memo, a debit invoice, or a positive invoice.

This screen helps user to create a debit note, which is raised against the expense account by selecting the document type as “debit note”, and the prefix will be created for the same.
