PO Amendment

Purchase Order amendment marks the closure of all specified transactions, amending the existing PO and actions associated with a purchase order, ensuring accurate procurement management.

Navigation path:

Supply Chain \ Purchase \ Transactions \ PO Amendment

  • Search screen displays the list of approved purchase Orders with the relevant details and its status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On -click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Cre. PO CS/AMD button we can create new PO amendment document by entering all the mandatory fields displayed in the Add dialog.
  • Select Single Close short or Bulk Close short as required.
  • Select the documents that are to be close short against the supplier and click Post button and the documents will be close shorted.
  • Click the Close short button, line type is updated as Closeshort for all the fetched line items.
  • Select to add a new item to the existing purchase Order and the type will be displayed as Addition.
  • Select Add PO Line(s) button to add the Line Items of selected Purchase Orders to edit the Quantity, Unit Cost, Disc%, Payment Term details and Location details the Type will be displayed as Modify.
  • Press the Cancel button to cancel the Current Purchase Order.
  • Once the order is closed shorted, in stocks, ordered bucket decreases, requested bucket increases, in budget, cancel amount increases and PO approved amount decreases, actual amount of the Purchase order will be reduced and purchase request will be increased in authorization budget.
  • The Purchase request of that particular order will be loaded again in Purchase request for order creation after close short.
  • System is not allowed to close short the order if it exists in receipt screen with ‘New’ or ‘QC completed’ status.
  • The Document status is changed to “Close shorted” after the document is close shorted.

The Purchase Order document can be amended both document wise and line wise. The Amendment button is enabled only if the document is in approved status.

  • The unit cost of the item may change after the Purchase order is approved. In such case, the purchase order should be amended for further updating.
  • The PO cannot be amended when the PO is in ‘Receipt’ status.
  • Enter the Amd. Reason for amending the document and click on the Amendment button in the header to amend the document.
  • Once the document is amended the amended details are updated in Purchase Order screen.
  • The Document status is changed to “Amended” after amending the document.
