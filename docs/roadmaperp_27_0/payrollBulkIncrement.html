It is a dedicated section where you input details about an employee's salary increase (or "increment"), including the percentage or amount of the raise, the effective date, and other relevant information, allowing you to formally record and apply the salary change to their payroll record.

Navigation path:

Payroll \ Transaction \ Employee Master \ Bulk Increment

Bulk Increment:

  • Search screen displays the list of increments with relevant details.
  • Click Search to filter all the records.
  • User can filter documents by entering search parameters in the header.
  • Using search, system displays results relevant to the entered parameters.
  • On click, the corresponding transaction record will be displayed.
  • Use to clear entered search parameters.
  • Use to close the screen.
  • By clicking the Add button, user can create a new document.

Bulk Increment Entry:

  • Click to add elements.
  • Enter the necessary elements.
  • Click to save.
  • Click to download the template and fill in the required details.
  • Click to upload the template.
  • Enable the Check Exception checkbox.
  • Click Post button to proceed.
