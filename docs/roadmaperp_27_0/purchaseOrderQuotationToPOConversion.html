Quotation to Purchase Order (PO) Conversion allows users to convert approved supplier quotations into firm purchase orders.

Navigation Path:

Supply Chain \ Purchasing \ Transaction \ Purchase order

  • Search screen displays the list of Purchase orders with the relevant details and its status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create Purchase Orders by entering all the mandatory fields displayed in the Add dialog.
  • Click on button, all the Pending RFQ are displayed.
  • Select the Pending RFQ radio button, system displays the approved quotation to be converted into order.
  • Filter the RFQ Document.
  • Select the Quotation and click on Create PO to create the purchase Order.
  • Select the Pending PR radio button, system displays the approved PR to be converted into order.
  • Filter the PR Document.
  • Select the PR and click on Create PO to create the purchase Order.
