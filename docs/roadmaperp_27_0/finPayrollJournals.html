A payroll journal is a type of journal voucher that is used to record the transactions related to the payment of wages and salaries to the employees of an organization. A payroll journal contains the details of the payroll process, such as the employee name, ID, department, pay rate, hours worked, deductions, taxes, net pay, etc. A payroll journal also includes the accounts that are affected by the payroll transactions, such as cash, wages expense, payroll liabilities, etc.

This screen is used to post the payroll Journals.

Navigation path:

Financials \Transactions\ Journal Voucher \ Payroll Journal

  • Search screen displays the list of Payroll Journals with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on the document to view the details.
  • After payroll is processed, the batch can be displayed.
  • Click on Create Journal and the journal gets created.
  • After journal is created, the batch is posted and it will be moved to payment.
  • View Payroll records button to show the all the employee salary for that particular batch.
  • Payroll records (department wise) will show the department wise calculated.
  • Journal can be printed using Print Jrnl. in PDF and Export to excel option also available.
