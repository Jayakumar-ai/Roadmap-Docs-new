A journal voucher is an accounting document used to record financial transactions in the general ledger. It explains the details of a transaction, including the accounts to be debited and credited, the amount, and a description of the transaction.

A journal voucher contains the details of the transaction, such as the date, amount, accounts, description, and authorization.

This screen is used to define Journal Voucher (BC).

Navigation path:

Financials \Transactions\ Journal Voucher \ Journal Voucher

Journal Voucher (BC)

  • Search screen displays the list of Journal Vouchers with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on the document to view the details.
  • View a Journal Voucher (BC) – Select the Journal voucher as “Journal Voucher (BC)”.
  • Click on Pending Party Doc. button to create the journal voucher from pending documents.

Create Document from Pending Documents

The credit documents can be created for the below pending transactions:

  • Pending Payables - Journal voucher can be created against the pending payable document.
  • Pending Receivables – Journal voucher can be created against the pending receivable document.
  • Pending Payable - Statutory - Journal voucher can be created against the pending Payable-statutory document.
  • Click on Pending Payables to view the Pending Party document.
  • Fetch the document based on due days, party, currency, Amount.
  • Enter the Current Payable Amount and select the check box.
  • Click Journal Voucher button to create the Journal Voucher.
  • Select the Unit Loc. and Click Ok and the Journal voucher will be created as shown below.
  • View Journal button consists of two buttons such as (a) Detailed journal can be viewed from Vw.Jrnl (Det) button and (b) the summary of the journal can be viewed from Vw. Jrnl (Sum) button. If the same account is found present twice, in the Vw.Jrnl (Sum) button, the amounts gets added up and the account is displayed once.

Creating New Document

To create new Journal voucher (BC), click on button.

  • Select a Unit from LOV.
  • Enter the Voucher Date. By default System date will be displayed. By default Trans. Currency as INR. User cannot edit the Currency.
  • Enter the Narration and save the entry.
  • Journal prefix and Voucher number gets generated.
  • Select the GL Account from LOV.
  • Choose a debit and credit amount, Both debit and credit amount should be same and a total is zero.
  • After entered the amount, click on Post for further approval.
  • Delete button is used to delete a document.
