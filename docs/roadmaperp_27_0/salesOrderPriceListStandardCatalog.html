Price List
Navigation Path

Option 1: Type the business function ID of Price List / Standard / Catalog in the search box the screen name will be displayed automatically and click on the GO button.

Option 2: Supply Chain \ Sales \ Transactions \ Price List-Standard-Catalog

  • Search screen displays the list of Price List with the relevant details and its status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On clicking the record, the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new Price List by entering all the mandatory fields displayed in the Add dialog.
  • All the Price list will be displayed in this screen.
  • Click to add new price list entry.
  • Enter Loc ID.
  • Enter/Select Customer.
  • Enter/Select Item.
  • Enter Price and discount percentage.
  • If required Enter Effective date from and date to.
  • Click to save the document.
  • Use the Amendment button to amend the price list.
  • The price list record will be changed to new state and the amendment can be made against the document.
  • Once the amendment is done for the item, the Amd. No. / Date will be updated appropriately.
  • Work Flow histories will be viewed using the View WF Hist. Provision.
  • On clicking post button, document is sent for Workflow approval.
  • To process the document in Workflow approval, navigate to approvals screen.
  • Click View Details to view the selected document.
  • Screen navigate into query screen to check the details.
  • Now navigate back to the approval screen.
  • Select the Approval/forward/Return/Wait radio button and click Process button to perform the corresponding Workflow process on the selected document.
Standard Price
  • By Clicking the Add button we can create new Standard Price by entering all the mandatory fields displayed.
  • Select the Unit Location and Unit is auto-Updated.
  • Choose the desired item from the LOV, Item Description is auto populated.
  • Select the Price UOM.
  • Select the Date From and Date To from the calendar.
  • Define the MAP price and Landed cost (If applicable) based on the effective date.
  • Selling Price is the sum of MAP and Landed Cost.
  • Click the Activate button to activate the standard price.
  • Click on the Revision button to revise the Standard price for the item.
  • Click to save the document.
  • Click on cancel button to cancel the standard price document.
  • Click on Print button to view the Report.
Catalog Price
  • By Clicking the Add button we can create new Catalog Price by entering all the mandatory fields displayed in the Add dialog.
  • Choose the desired item from the LOV.
  • Choose the Catalog Type from LOV.
  • Select the Price Level.
  • Define the price based on the effective date.
  • Select the Currency from LOV.
  • Enter the Min and Max Disc%.
  • Select the From Date and To Date from the calendar.
  • On clicking post button, document is sent for Workflow approval.
  • Work Flow histories will be viewed using the View WF Hist. Provision.
  • Click on Print button to view the Report.
