The defect groups can be defined in this screen. This screen is used to add, modify, and delete defect groups.

Navigation Path:

Quality Control \ Setup \ Setup - Quality

Add a Defect Group:

  • Click the add icon to create a new Defect Group.
  • Enter the Defect Group Description.
  • Click to save.

Modify a Defect Group:

  • Only descriptions can be modified.
  • Click on the Defect Group.
  • Change the Description.
  • Click to save.

Disable Attribute Specifications:

  • Only unused Specifications can be disabled.
  • Select the Defect Group.
  • Disable the Active flag.
