A Contra voucher is used to record transactions that involve the transfer of funds between cash and bank accounts or between two bank accounts within the same organization.

This screen is used to enter the Contra voucher between bank and cash.

Navigation path:

Financial \ Transaction \ Payment & Receipts \ Contra Voucher

  • Search screen displays the list of Contra Voucher with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on the document to view the details.
  • Click to add a new contra voucher.
  • Select the From Bank/Cash A/C.
  • Select the To Bank/Cash A/C.
  • Enter the Transfer Amt.
  • Select the Pay Mode.
  • Enter the Ref.No.
  • Click to save the header.
  • If required, enter the From bank charges in the line details.
  • Click Create Journal check box to create the journal.
  • Click on View Journal button, to view the summary and details of the Journal.
  • Click on Post, and the document can be sent for approval.
