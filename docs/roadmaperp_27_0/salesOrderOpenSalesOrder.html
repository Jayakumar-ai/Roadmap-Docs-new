Contract price is defined in the Open Sales Order screen.

Navigation Path

Supply Chain \ Sales \ Transactions \ Open SO

Open Sales Order Overview
  • Open SO - Contract price can be fixed in this screen against the item.
  • Open SO Amendment - The contract price for the item can be amended in this screen.
Find Page
  • Search screen displays the list of Open Sales Order with the relevant details and its status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On clicking the record, the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new Open Sales Order by entering all the mandatory fields displayed in the Add dialog.
Create Open Sales Order
  • Enter/Select the location ID, unit will be displayed automatically.
  • Select the Customer from LOV. Currency & payment term are auto updated for the selected customer.
  • Select the OSO Pfx. & Date.
  • System date is auto populated for the Doc. Date.
  • Enter the PO No. & Date.
  • Click button to create New Open Sales Order.
Open Sales Order Line Items
  • Enter the Date from and Date To.
  • Select the Item from LOV.
  • Enter the Price for the Item based on the Price level as Line/Range.
  • Enter the Disc%.
  • Select the HSN/SAC Code.
  • Enter the Reference.
  • The item for the rate contract can also be retrieved using the Fetch customer item button.
  • Enter/Select the Item from the LOV.
  • Enter the Discount % for the Item and Tax set from the LOV.
  • The line item can be deleted using the Delete button in the line item.
  • Click on Cancel button to cancel the document.
  • On clicking post button, document is sent for Workflow approval.
  • The necessary work flow operations are done in the Workflow document control screen.
Workflow Approval Process
  • To process the document in Workflow approval, navigate to approvals screen.
  • Click View Details to view the selected document.
  • Screen navigate into query screen to check the details.
  • Now navigate back to the approval screen.
  • Select the Approval/forward/Return/Wait radio button and click Process button to perform the corresponding Workflow process on the selected document.
