Visitor Appointment

Managing visitor appointments in gate entry involves scheduling and tracking visitors' details to ensure a smooth and secure process.

Navigation path:

Supply Chain Management \ Gate Entry \ Transaction \ Visitor Appointment

  • Search screen displays the list of Visitor Appointment with the relevant details and its status
  • Click on Search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using Search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button in the find screen, we can create a new visitor appointment document
  • Select the Unit
  • Enter Time from and Time To
  • Select Appointment By
  • Select Appointment Type
  • Enter Appointment. To.
  • Click to Save.
  • Click on Post button and the document will be posted
