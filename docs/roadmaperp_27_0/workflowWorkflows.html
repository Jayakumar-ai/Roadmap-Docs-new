The Authorization for the workflow transaction records are defined in the following screen. The Authorization for the document may have more than one stage and the transaction Document will be subjected to cross the defined number of stages for approving the Transactions.

Navigation path:

Workflow Management \ Transaction \ Workflow Approval Access

  • Search screen displays the list of Workflow approval access of various transactions with the relevant details and its status.
  • Click on Search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can add new Workflow approval access by entering all the mandatory fields displayed in the Add dialog.
  • Select the Workflow ID from LOV, Workflow Desc. is auto populated.
  • System date is auto updated.
  • Module of the selected Workflow ID is auto assigned.
  • Enter the validity period for the Workflow authorization in Eff. From and Eff. To Date.
  • Click on button to create the workflow approval access document for the selected transactions.
  • System navigates to the approval access screen and Workflow approval access document is created with the document Number as shown above.
  • If the approval authorization is set for the employee, the user possesses the sole right to approve or cancel the record. Else the document will be forwarded to the user defined in the employee hierarchy.
  • Enter the Code and Code Desc., Code Short Desc. to define the Workflow approval stage.
  • Select the Notify to as All/Creator/Receiver from the list item.
    • If set as Creator, the progress of the transaction will be notified to the creator of the document.
    • If set as All, the progress of the transaction will be notified to all the users mapped to the workflow approval access of the corresponding transaction.
    • If set as Receiver, the progress of the transaction will be notified to the receiver to whom the document is forwarded.
  • The authorization of the document will be defined for each stages of approval.
  • Enable the IM flag to receive the notifications on the Workflow approvals through Internal messages.
  • To receive the notifications on the Workflow approvals through Mail, Enable the Mail flag.
  • Select the SMS flag to receive the notifications via mobile SMS.
  • Select the Whatsapp flag to receive the notifications via Whatsapp.
  • Select the Template ID for SMS and Whatsapp. According to template, notification message is sent to the defined SMS and Whatsapp number.
  • Enter/Select the Entity.
  • Enter/Select the Unit.
  • Enter/Select the Employee/Position of the employee.
  • Enter the authorization validity period of the transaction in From & To.
  • Enter the authorization value of the transaction.
  • Click on button Save the lines.
  • Click on Post button to approve the Workflow approval access for a particular transaction.
