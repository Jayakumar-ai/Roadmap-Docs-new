Area

An area is an organizational unit that indicates where a functional object is physically installed in a plant section. A functional object is a technical system, building, or part thereof that can be maintained. Location allows a plant to be classified according to spatial or situational criteria, such as buildings, floors, rooms, etc

The area is manually entered and the units are associated with its corresponding location. The area cannot be modified or deleted when the child record exists, but the descriptions can be modified.
