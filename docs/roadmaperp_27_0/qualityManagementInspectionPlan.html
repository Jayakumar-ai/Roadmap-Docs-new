A quality plan will be derived for the Item with its characteristics and specification value should meet the plan while inspecting the Items. The Inspection plan is five types,

  • Inspection Plan – Incoming
  • Inspection plan – In process
  • Inspection Plan – Final
  • Inspection Plan – Customer
Navigation Path:

Quality Control \ Setup \ Inspection Plan

Inspection Plan – Search

  • Search screen displays the list of Inspection plan with the relevant details and its status.
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using clear icon, entered search parameters can be cleared.
  • To close the screen, use close icon.

Inspection Plan – Incoming

  • Select the Incoming flag and click on Search to filter only the Inspection Plan Incoming documents.

Add Inspection Plan – Incoming

  • Click and select the Incoming button to create the Inspection plan for Incoming.
  • Select the Location ID, Unit is auto populated.
  • Enter the Plan Name.
  • Select the Item for which the quality plan to be created.
  • Select Supplier ID from LOV.
  • Enter the date from and date to.
  • Click to save the header.
  • Click in the Line item to create parameters.
  • Select the Characteristics from the LOV.
  • Select the UOM for the characteristics.
  • Select the Std. Operator.
  • Enter the Spec. value for the Variable specification type.
  • Enter the Lower and Upper Specification Value.
  • In case of Attribute specification, select the specification from the LOV.
  • On clicking post button, document is sent for approval.
  • Use the Cancel button to cancel the plan.

Inspection Plan – In Process

Inspection Plan - In Process defines certain specification and parameters levels to inspect the process in quality while manufacturing. Items should meet those specifications for that particular process.

Add Inspection Plan – In Process

  • Select the TSA / In process Inspection flag and click on search to filter only the Inspection Plan In process documents.
  • Click and select the TSA / In process inspec. button to create the Inspection plan for In Process.
  • Select the Location ID, Unit is auto populated.
  • Enter the Plan Name.
  • Select the Item for which the quality plan to be created.
  • Enter the Inspection plan Validity date from and date to.
  • Click to save the header.
  • Click in the Line item to create parameters.
  • Select the Characteristics from the LOV.
  • Select the Type.
  • Select the Process ID.
  • Select the UOM for the characteristics.
  • Enter the Spec. value for the Variable specification type.
  • Enter the Lower and Upper Specification Value.
  • In case of Attribute specification, select the specification from the LOV.
  • On clicking post button, document is sent for approval.
  • Use the Cancel button to cancel the plan.
