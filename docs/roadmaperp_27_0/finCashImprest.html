A business uses a Cash/Imprest to cover small, regular expenses. The imprest is a cash account that always has a fixed balance, because it is refilled frequently. Creating an imprest for the company can help the user to control and monitor the petty cash expenditures that occur in the daily operations of the business.

This screen is used to create Cash/Imprest.

Navigation path

Setup \ Cash/Imprest

  • Search screen displays the list of Cash/Imprestwith the relevant details.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new Cash/Imprest
  • Enter/Select the Unit from LOV.
  • Enter the Cash ID and Cash Name.
  • Select the Employee from LOV.
  • Enter the Address1, Address 2 and Address 3.
  • Enter the Telephone No.
  • Enter the Email ID.
  • Select GL Group.
  • Select Territory
  • Enter Payment Term.
  • In Account Tab, Click button to add a GL Group
  • Select a GL Group for cash account creation.
  • Prefixes are separated for bank & Cash. Prefix should be separately given for each cashier for payment, receipt.
  • Click Activate Button to activate the Cashier and the status will be changed from Draft to Active.
