User can utilize this screen to define the travel expenses details.

Navigation path:

Payroll \ Setup \ Setup-Travelling Expenses

Expenses Group:

  • Click to Create.
  • Enter expense group.
  • Select type.
  • Click to save.

Expenses Code:

  • Click to Create.
  • Enter expense code.
  • Select expense group.
  • Select type.
  • Select account.
  • Click to save.
