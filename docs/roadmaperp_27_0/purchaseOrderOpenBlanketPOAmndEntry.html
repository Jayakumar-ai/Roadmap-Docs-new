The Open Purchase Order document can be Amended using the Open/Blanket PO Amnd./Entry. The Amendment of the Open/Blanket PO is done by the Modify the Price, Addition of Item and Deletion of Existing Items or any changes in the Terms and Conditions.

  • Click Amend Open PO Button, system navigates to the list of approved Open blanket orders.
  • Select the document and choose the Amendment Reason.
  • Click OK button, Amendment document created and Automatically screen Navigate into Transaction screen.
  • A unique document Number will be generated for Open Purchase Order Amendment.
  • The line items of the open order document are fetched and selected using the Fetch PO Lines button.
  • The Revised price for the line item is to be entered in the new unit cost field.
  • The line items can be added or deleted for the open order document.
  • Save the Document.
  • The Document will be sent for approval using the Post button.
  • Using Cancel button, the document can be cancelled.
  • In case of Doc. Forward, Log in Forward user.
  • Click on View details to view the specific document.
  • Screen navigate into query screen to check the details.
  • After click the close button document navigate into Approval screen.
  • Choose the Approval/forward/Return button field and click Process button required process performed.
