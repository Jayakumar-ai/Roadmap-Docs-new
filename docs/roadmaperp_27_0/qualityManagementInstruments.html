Instruments which are subjected to various types of study are created in the following screen.

Navigation Path

Quality Management \ Transactions \ Measurement System Analysis

  • Search screen displays the list of Instruments with relevant details and their status.
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click the Add button to create the instrument.
  • Enter/Select the Loc ID from LOV.
  • Enter the Instrument Name and Description.
  • Enter/Select the Instrument Sub Group and Group from LOV.
  • Select the Make from LOV.
  • Enter/Select the Instrument Location.
  • Select the Calibration Method of the instrument from LOV.
  • Location defaults to Inside, can be changed to Outside.
  • Enter the Serial/OE. No.
  • Select the Calibration Agency from LOV.
  • Select the UOM/Range from LOV and enter the values.
  • Click on to save.
  • Following studies are listed under the Calib./Study tab:
    • Calibration
    • Inspection
    • Linearity Study
    • Bias
  • The instrument will be subjected to these studies sequentially.
  • Status of document and study will initially be New.
  • Select the required study.
  • Enter the Period and select calibration duration (Year(s)/Month(s)/Day(s)/Week(s)).
  • Enter the Last Calibration Date. Next Calibration Date is auto calculated.
  • Enter Notify Days to indicate due days for next calibration.
  • Characteristics of gauges are entered in the Characteristics tab.
  • For Variable type, enter Value. For Attribute type, enter corresponding specification.
  • Enter the Supplier for Insurance details from LOV.
  • Select Start Date and End Date for Insurance.
  • Enter the Amount Assured.
  • Enter the Policy Number.
  • Enter the Insurance and Premium Amount.
  • Select the Item from LOV.
  • For Sales, enter Sold Date and Sold To details.
  • Enter Supplier Name and select PO Date of the instrument.
  • Click on Post button to send the document for approval.
  • Instruments can be set as Outdated using the Obsolete Button.
  • Instruments can be moved to History using the Remove button.
  • Status changes to In Use from New once gauge is activated.
  • Document status is set to Obsolete when instrument is obsolete.
  • Spare parts required for gauges are selected from Item LOV.
  • Description of the item auto-populates.
  • Enter required quantity of spares.

Template

  • Select the Download Template button.
  • Enter Unit, Indtr. ID, Instrument Name, Sub Group, Group, Make, Model, Location, Calib. Method, Serial No, Calib Agency, Owner, UOM, Range Min, Range Max, Reference, Least Count, Accept Criteria.
  • Click on to save the Template File.

upload

  • Select the Load button.
  • Select the Template File.
  • Select Open button to upload the filled template.
