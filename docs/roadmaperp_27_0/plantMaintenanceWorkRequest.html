A work request in plant maintenance is a document that is used to alert the maintenance team about issues that require their attention. It highlights a problem or defect that inhibits the operation of a particular asset or facility. Work requests are created when there is sudden breakdown of machines/equipments in the work area.

  • Search screen displays the list of Work Request with the relevant details and its status
  • Click on Search to filter all the records
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon
  • By Clicking the Add button we can create Work Request for the required Equipment.
  • Enter / Select the Loc ID from LOV.
  • Enter the required date and Request Desc.
  • Enter / Select the Equipment from LOV.
  • Enter / Select the Requested By from LOV
  • Click on to create the new Work Request
  • Enter / Select the Shift and Failure if required.
  • Enter/Select the Stop details if machine is stopped.
  • Click on to Save the document.
  • On clicking Post button, document can be sent for approval.
