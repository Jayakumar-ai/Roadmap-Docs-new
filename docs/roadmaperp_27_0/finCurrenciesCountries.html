The system already has preset currencies and countries for financial transactions outside of the company. If needed, users can also add new currencies, countries, cities, and villages.

This screen is used to create a Business Unit.

Navigation path:

Setup \ Currencies/Countries

  • Click to create a new currency Type.
  • Enter Currency ID.
  • Enter Currency Name.
  • Enter Currency Symbol.
  • Enter Currency Format.
  • Enter Currency Integer.
  • Enter Fraction and Decimal details.
  • Click on Check Ex. Range checkbox if the exchange rate to be checked for the currency type.
  • Click on the Active checkbox to activate the Currency Type.
  • Click to save.

Countries

  • Click on the Active checkbox to activate the Country’s Type.

Port

  • Click on the Active checkbox to activate the Port Type.
