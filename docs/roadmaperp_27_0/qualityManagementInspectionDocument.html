Inspection documents are converted from the Inspection created from various transactions are processed as follows

Navigation path:

Quality Management \ Transaction \ Inspection Document

  • Search screen displays the list of Inspection document with the relevant details and its status.
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By clicking button, yet to be processed pending inspection are displayed as shown below.
  • Filter the pending inspection details with the relevant search fields in the header.
  • Click on Search button to view the inspection request details.
  • Enter the Process Qty for Inspection.
  • Select the pending inspection and click on Create QC Doc. Button to create the Inspection Document.
  • Inspection document is created as shown.
  • On post button, document is sent for approval.
  • The Inspection report can be run using button.
  • The Inspection request can be cancelled using the Cancel button and the document is reversed to Pending Inspection screen.
  • If Inspection plan exists, characteristics are auto inserted.
  • Enter the No. of Samples and No. of Observations.
  • Click on the Smp./Obs. button and enter observation values.
  • Click on the Smp./Obs.button.
  • Enter the observation values for each sample & save.
  • Click on the Obs./Smp.
  • Enter the sample observation values & save.
  • Observation results are displayed for Variable, Attribute and Text types.
  • Atnd. / Not Atnd. / Obs. Not Entered.
  • Enter the remarks if required and save it.
  • AOD button will be enabled if Accept on deviation quantity is entered for the line item.
  • Enter/Select the Deviation from LOV.
  • Enter the AOD Qty matching with AOD qty of the line item.
  • Under the Defects tab details of rejection quantities are entered by selecting the defect type.
  • Select the Defect from LOV.
  • Enter Defect Quantity.
  • Enter the Primary and Secondary Rejection if Applicable.
  • Enter the remarks and Save.
  • Click on button to attach the file.
  • Click on button to delete the attached file.
  • Click on button to reload the attached file.
  • Click on button to open the attached file.
  • Click to save.
  • Click post button and the document will be sent for approval.
