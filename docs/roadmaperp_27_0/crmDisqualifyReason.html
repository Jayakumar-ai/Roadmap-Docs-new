A disqualify reason refers to the specific rationale provided when a lead is marked as unqualified or no longer pursued. This helps maintain an organized and transparent sales process by documenting why certain leads did not progress., Disqualify reason are all configured in this screen.

Navigation path:

CRM \ Setup \ Setup-Marketing \ Lead \ Disq.Reason

  • Click on button
  • Enter the Reason
  • Select the Active flag if the Disq. Reason is to be used in transactions
  • Click to save
