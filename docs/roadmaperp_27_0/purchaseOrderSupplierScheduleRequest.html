The Supplier Schedule Request feature allows Business Units to request specific delivery schedules from suppliers. This functionality helps in aligning procurement with production or project timelines by specifying required delivery dates for goods or services.

Navigation path:

Supply Chain \ Purchasing \ Transaction \ Supplier Schedule Request

  • Search screen displays the list of supplier schedule requests with the relevant details and its status.
  • Click on search button to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search button, system displays the results relevant to the search parameters entered.
  • On clicking; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new supplier schedule request by entering all the mandatory fields displayed in the Add dialog.
  • Choose the location and Unit field is auto updated.
  • Choose the Doc Prefix and service type.
  • Choose the Warehouse and Department name in LOV.
  • Enter the Reference.
  • To click button Document to create the supplier schedule request and navigated to the Transaction screen.
  • Choose the Item in Item LOV.
  • Give the Firm and Tentative Qty.
  • Choose the bucket type of Day/week/Month.
  • Give the Firm period or Tentative period.
  • The Document will be sent for approval using the Post button.
  • Using Cancel button, the document can be cancelled.
  • To approve the document, Navigate to the Workflow approvals screen.
  • Click view details For specific document.
  • Screen navigate into query screen to check the details.
  • After click the close button document navigate into Approval screen.
  • Choose the Approval/forward/Return button field and click Process button, required process performed.
