The Quality characteristics / parameters can be defined in this screen. Characteristics can be added, modified, and disabled as required.

Navigation path:

Quality Control \ Setup \ Setup - Quality

Add Characteristics:

  • Click the add icon to create a new characteristic.
  • Enter the Characteristics.
  • Select the Group Description.
  • Select the Testing Description.
  • Select Check Basis.
  • Select UOM.
  • Select Instrument Group.
  • Select the Type.
  • Select the Group Type.
  • Select the Sample Type.
  • Select the Input Option.
  • Click to save.

Modify Characteristics:

  • Select the required Characteristic.
  • Make the necessary changes.
  • Click to save.
  • Modification is allowed only before transactions are created.

Disable Characteristics:

  • Only unused Characteristics can be disabled.
  • Select the Characteristic.
  • Disable the Active flag.
