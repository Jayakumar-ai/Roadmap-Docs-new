Appl. Ctrl. (Plant Maintenance)

This screen is used to define the application control details of Plant Maintenance.

Navigation path:

Plant Maintenance \ Setup \ Setup-Plant Maintenance \ Application Control

  • Click to add the Unit
  • Enter the Unit.
  • Select the Work req. to work order completion as Manual or Automatic.
  • Select the Equipment ID Creation whether it is Manual or auto.
  • Select the type of Spare Consumption.
  • Auto hand over can be checked or unchecked.
  • WO Breakdown can be Checked or unchecked.
  • Material Req. mandate can be checked or unchecked.
  • Click to save
  • By clicking Post button the document can be forwarded for approval
