A campaign is a well-organized marketing effort designed to meet particular business goals, such as attracting potential customers, boosting sales, or enhancing brand visibility, the Campaigns types are configured in this screen.

Navigation path:

CRM \ Setup \ Setup-Marketing \ Campaign \ Campaign Types

  • Click on button
  • Enter the Campaigns id
  • Enter the Campaigns Description
  • Select the Active flag if the Campaign is to be used in transactions
  • Click to save
