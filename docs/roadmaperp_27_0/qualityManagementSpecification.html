The Quality specifications can be defined in this screen. Specifications can be added, modified, and disabled as required.

Navigation path:

Quality Control \ Setup \ Setup - Quality

Specification:

  • Click the add icon to create a new Specification.
  • Enter the Specification.
  • Enter the External Specification Description.
  • Click to save.

Modify Specifications:

  • Select the required Specification.
  • Make the necessary changes.
  • Click to save.
  • Modification is applicable only before transactions are created.

Disable Specifications:

  • Only unused Specifications can be disabled.
  • Select the Specification.
  • Disable the Active flag.
