The required items can be purchased from the different suppliers. But there may be a particular supplier from where the items are purchased for their price, quality and delivery factor. The Particular items are mapped to the corresponding suppliers and such suppliers are called approved Suppliers.

Navigation path

Supply Chain \ Subcontracting \Setup\ Approved Suppliers.

  • Search screen displays the list of Approved Suppliers with the relevant details and its status
  • Click on Search button to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new Approved Suppliers.
  • Enter/Select Unit
  • Enter/Select Doc.Pfx
  • Select Supplier ID from LOV, Supplier name will be automatically fetched
  • Select Item from LOV; other details will be fetched automatically
  • Enter the Warranty duration
  • Select the Type.
  • Click (save)
  • Click on Process button.
  • Clicking the Add button.
  • Select the process
  • Enter the Lead Time
  • Enter the Capacity limit
  • Click (save)
  • “Post” the document and the document can be forwarded for approval
