Actions taken against the defect are mapped in this screen.

Navigation Path:

Quality Control \ Setup \ Setup – Quality

Add Defect Action:

  • Choose the Defect LOV.
  • Click the add icon to create.
  • Map the action to the defect codes by selecting the Action from the LOV.
  • Click to save.

Modify Defect Action:

  • Only descriptions can be modified.
  • Click on the Defect Action.
  • Change the Description.
  • Click to save.

Disable Defect Action:

  • Only unused profile actions can be disabled.
  • Select the Defect Action.
  • Disable the Active flag.
