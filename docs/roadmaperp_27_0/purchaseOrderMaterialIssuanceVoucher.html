A material issuance voucher is a document that authorizes the release of materials between the warehouses or another location, material issuance voucher records the details of the materials issued.

Navigation path:

Supply Chain \ Inventory \ Transaction \ Material Issuance Voucher

  • Search screen displays the list of material Issuance voucher with the relevant details and its status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On -click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Once the GRN is approved, the Material Issuance voucher is posted automatically, user can use this screen to view the details of the document.
