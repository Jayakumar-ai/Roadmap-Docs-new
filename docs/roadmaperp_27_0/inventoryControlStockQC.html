STOCK QC is a process that involves inspecting, testing, and verifying the quality and condition of the inventory items.

This screen is used to check the QC for stored item. The stock QC created is of three types as follows.

  • Internal Stock
  • Customer
  • Third Party
Navigation path:

Supply Chain Management \ Inventory \ Transaction \ Stock QC

  • Select the document
  • Lot/Serial details will be shown in Lot/Serial dialog.
  • Enter Process Quantity
  • Check the select flag and Click ok
  • Press the Create issuance document button to create the material issuance document.
  • Select Date and Click ok.
  • The issuance document will be created
  • While posting the material issuance document, the inspection document of corresponding types are created as explained below.
  • Material Issuance document is created from stock QC as shown above.
  • Click on Post button to post the Material Issuance document.
  • Check for the stock qty levels In the respective warehouses in the Stocks screen
