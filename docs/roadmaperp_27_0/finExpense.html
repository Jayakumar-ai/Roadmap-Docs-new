Registering Invoice for Expense

  • Select Type as Exp.
  • For Expense based GL account should be selected and amount should be enter in the unit cost field.
  • If Dr is selected in the Dr/Cr tab, the amount gets added up and If Cr is selected the amount gets subtracted.
  • According to the HSN code, the GST % will be fetched automatically.
  • Click on create journal to view the journal/directly click post button, journal is created automatically and it will be posted.
  • Press the post button to complete the entry and the document can be forwarded for approval.
