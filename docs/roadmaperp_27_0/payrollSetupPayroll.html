Employee payroll configurations can be defined using this screen.

Navigation path:

Payroll \ Setup \ Setup-Payroll

Payroll Element:

All payroll elements for additions and deductions based on company policy can be defined here.

  • Click to create.
  • Enter the Element and description.
  • Select the Type.
  • Select the Account Type.
  • Click to save.
  • Enable the Active button to activate the element.

OT Prefixes:

Overtime prefixes and ratios can be defined in this screen.

  • Click to create.
  • Enter the overtime prefix.
  • Enter the ratio.
  • Enable Default checkbox to prioritize the element.
  • Click to save.

TDS:

TDS statutory details and slab rates can be viewed using this screen (Sec-10(14)H).

Professional Tax:

Professional tax ranges for payroll elements can be defined here.

  • Click to create.
  • Enter the element.
  • Select the source.
  • Click to save.
