Stock Opening Balance is the quantity and value of inventory items that a company has at the beginning of a new financial period

Navigation path:

Supply Chain Management \ Inventory \ Transaction \ SCO Opening balance

  • Using search, system displays the results relevant to the search parameters entered.
  • On -click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
