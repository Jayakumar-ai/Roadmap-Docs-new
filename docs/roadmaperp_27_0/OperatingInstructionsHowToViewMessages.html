This screen explains how to view and manage messages within the application.

How to view messages:

  • Go to the IM / Mail / SMS / WhatsApp screen.
  • All messages can be viewed from this screen.

Internal Messages:

  • Internal messages are sent during the approval of workflow documents.
  • The Inbox contains the following columns:
    • Sent Date
    • Sender
    • Subject
  • Click the Read Msg button to view the full details of the message.
  • Messages can be archived using the Archive button.
