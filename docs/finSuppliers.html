Suppliers are entities that provide goods or services to other entities, such as customers, businesses, or organizations. Suppliers can also belong to different groups or categories based on their affiliation, location, industry.

User can also enter the supplier's address, statutory details, supporting documents, and other information.

Navigation path:

Setup \ Suppliers

  • Search screen displays the list of Suppliers with the relevant details.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click, the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new Suppliers.

Address

  • Enter the Party ID.
  • Enter the Party Name
  • Enter the Print name
  • Select the Sub group from LOV; Group, Payment term, Ship Via and INCO Term get populated automatically based on the sub group selection.
  • Enter the Supplier Address, City from LOV, Zip, Telephone number and Mobile number.
  • Click to Save the entry.

Location

  • Location will be automatically created from the address.
  • If required, Click to add a new Location
  • Enter the Location Description.
  • Enter the Address1.
  • Select the City from LOV.
  • Select the GST classifications.
  • Select the GST Type.
  • Enter the GSTIN No. for registered suppliers.
  • Select the Scheme.
  • Select the location type Default Location, Bill From and Ship From.
  • Click to save the Entry.

GL Group

  • Click to add GL Group.
  • Select the Acct. Class.
  • Select the GL Group from LOV.
  • Click to save.

GL Account

  • Click to add GL Account.
  • Select the Acct. Class.
  • Select the Account from LOV.
  • Click to save.

Currency

  • This tab page is used to specify the transaction Currency for the Supplier.
  • The given Currency cannot be changed if transaction already exists for the supplier
  • Default currency is set as per the location, if required user can change the default currency and add new currency to the supplier in this tab.
  • Click to add Currency details
  • Select Allowed curcy from LOV
  • Enable the active checkbox
  • Click to save.

Deduction

  • Enter the threshold limit, if required.
  • Click to save.

ITR Details

This Tab is used to give the ITR Details.

  • Click to add ITR details
  • Select TDS Applicable or Not applicable from the drop down list.
  • Select the Year form LOV.
  • Click to save.
