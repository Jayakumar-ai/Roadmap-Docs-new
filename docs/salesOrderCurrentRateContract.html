All the approved rate contracts are displayed in the below screen.

Current Rate Contract
Navigation Path

Supply Chain \ Sales \ Transactions \ Open SO \ Open SO Amendment \ Add

  • Open SO Approved Document are displayed in the Current Rate Contract Screen.
  • Check the Hold Flag Document to hold the rate contract.
  • To amend the Open SO, click on SO Amendment button.
Open SO Amendment
  • On clicking SO amendment button, select the amendment reason from LOV to amend the Open SO.
  • Click on Ok button to amend the open SO.
  • Document status will be changed from approved to New Status.
