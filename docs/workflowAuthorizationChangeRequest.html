User Authorization defined for the transaction is changed using the below screen.

Navigation path:

Workflow \ Transaction \ Authorization Change Request

  • Search screen displays the list of Authorization change request of various transactions with the relevant details and its status.
  • Click on Search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can add new Authorization change request by entering all the mandatory fields displayed in the Add dialog.
  • Select the Location and Unit from the LOV.
  • Select the Type as Modify to change the authorization for the transactions.
  • Select To Employee from LOV.
  • Doc. Date is auto populated.
  • Click on button to change the authorized person specified in From Employee & To Employee.
  • Click on Post and the document can be forwarded for approval to change the authorization.
