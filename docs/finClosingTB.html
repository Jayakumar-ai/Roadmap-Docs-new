A Trial Balance is a statement that keeps a record of the final GL account balance of all accounts in a business. This screen is to update/view the closing TB.

All the adjusted document details are displayed in this screen.

Navigation path:

Financials \ Transaction \ Fin Year closing \ Closing TB

Closing TB

  • Select the Unit, Voucher Date will be displayed default as Cut-Off Date.
  • Select the Prefix and enter the Narration.
  • Save the Entry. Document number gets generated.
  • Select the Accounts enter the Debit and credit amount.
  • Both the debit and credit amount should be equal. If the amount is not same, system will not allow to entry complete the document.
  • Click on post button, approve the document.
  • Cancel button, it is used to cancel the document.
  • Print PDF and Export Excel button, it is used to view a report as either PDF or excel files.
