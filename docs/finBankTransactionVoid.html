This screen is used to void any bank transactions. While voiding a document, journal gets reversed and contra documents will get created and viewed in Purchase bills& Customer document screen. Document status will be changed as Void.

Navigation path:

Financials \ Transactions \ Payment & Receipts \ Bank Trans. Void/Clear - Multi

  • Query the voucher document.
  • Select the document and click on Void.
  • Void/Clear document window gets opened.
  • Enter the date, Narration and click on Void button.
  • Once the document is void, the same document will not get displayed.
  • Navigate to Bank transaction query screen (Bank payment or receipt) and query for the record. The status will get changed to void and the reverse journal is also created.
  • Contra documents will be created in Supplier documents & Customer documents query screen.
  • Once Void The Voucher Status Updated The Query Screen.
  • Void The Voucher Journal Also Change & Updated In Query Screen.
