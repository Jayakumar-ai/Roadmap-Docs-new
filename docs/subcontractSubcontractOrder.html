A subcontract order is used when outsourcing part of the manufacturing process or production process to an external vendor

Navigation path

Supply Chain \ Subcontracting \ Transaction\ Subcontract Order

  • Search screen displays the list of Subcontract orders with the relevant details and its status
  • Click on search button to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • On clicking search button, system displays the results relevant to the search parameters entered.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • By Clicking the Add button we can create new Subcontract Order by entering all the mandatory fields displayed in the Add dialog
  • Select Supplier ID from LOV

  • Select the Item from the LOV; Item Rev., UOM and Item Description details get displayed automatically.
  • Enter the Ordered Quantity.
  • Enter the Unit Cost.
  • Click to save the Document.
  • The entire order or particular line can be cancelled by header using Cancel button or by line by pressing delete button in the Lines tab.
  • When the document is saved, the Subcontract order No. will be generated automatically.
  • Click on Include Cost Button and the SCO Value will be calculated automatically based on the process
  • Click on Gen MRP button and Raw material requirement will be generated
  • Click Post and the document can be forwarded for approval.
