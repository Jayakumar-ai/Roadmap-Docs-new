Fixed assets normally include items such as land and buildings, motor vehicles, furniture, office equipment, computers, fixtures and fittings, and plant and machinery. These often receive favorable tax treatment (depreciation allowance) over short-term assets.

This screen is used to create Fixed Assets.

Navigation path:

Financials \ Transactions \ Fixed Assets \ Fixed Assets

  • Search screen displays the list of Fixed Asset with the relevant details and status.
  • Click on search to filter all the records.
  • User can filter the respective documents by entering the search parameters at the header.
  • Using search, system displays the results relevant to the search parameters entered.
  • On-click; the corresponding transaction record will be displayed.
  • Using icon, entered search parameters can be cleared.
  • To close the screen, use icon.
  • Click on the document to view the details.
  • Click on to create Fixed asset
  • Select Loc ID.
  • Select Asset Location.
  • Select Vou. Date
  • Enter Asset Desc.
  • Select Sub Group.
  • Select Source as Direct Entry, Opening Bal or WIP.
  • Select the Owning Dept.
  • If shift is applicable to the asset, enable shift applicable checkbox.

Financial Info

  • Enter the activation date as voucher date.
  • Enter the Asset Life in year, Life in days and Expiry date will be calculated automatically.
  • In Asset Value details, enter the asset value.
  • Enter the Salvage %.

GL Account

  • Select the GL Acct.No.
  • Click to Save.
  • The Target GL Account will be displayed automatically.

Purchase Det.

  • Select the Pur.Ord.No.
  • Select the Supplier ID.
  • Select the GRN No.
  • Enter the Installation Date.
  • If required, Enter the MIV Details.

Warranty/AMC Details

  • Click on to create.
  • Select the Type.
  • Enter Date from and Date To.
  • Select Supplier Name.
  • Click to Save.

Insurance Details

  • Select the Supplier Name.
  • Enter Date From and Date To.
  • Enter Ins.Cov.
  • Enter the Policy No.
  • Enter the Sum Assured.
  • Enter the Premium Amount.
  • Enter Freq.Every.
  • Select the Year(s) or Month(s).
  • Enter Load.Prem.Paid.On and Next.Pre,.Dueon./li>
  • Click to Save.

Mtfr. Details

  • Select the Make or Model.
  • Enter the Year, Engine No, Chasis No, Registration details, Mftr details.
  • Enter the Serial No.
  • Click to Save.
  • Click on Cre. Journal button to create the journal for fixed asset.
  • Click on View Journal button to view the Journal.
  • Click on Post button, the document can be sent for approval, once approved, the status of the Fixed asset will be changed as Active.
