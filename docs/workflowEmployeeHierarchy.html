The Hierarchical reporting of the employees involved in the Transactions are configured in the following screen.

Navigation path:

Workflow Management \ Set Up \ Employee Hierarchy

  • Click button to create new.
  • Enter/Select the Employee ID, the Employee name will be auto populated.
  • Enter/Select the Reporting Entity.
  • Enter/Select the Reporting Unit.
  • Enter/Select the Reporting to Employee ID, the Employee name will be auto populated.
  • If the default flag is checked, the default reporting person is auto assigned for the WF authorization for approving the transaction entries.
  • Click to save.
