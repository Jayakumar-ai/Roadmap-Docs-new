This screen is used to define the application control details of Payroll management.

Navigation path:

Payroll \ Setup \ Appl. ctrl.-Payroll

Employee Portfolio:

  • Mode:
    • Manual – Employee ID is created manually.
    • Auto – Employee ID is automatically created.
  • Emp Next ID:
    • Enter the sequence of the employee ID.
  • Required:
    • Yes – Employee last name is mandatory.
    • No – Employee last name is not mandatory.
  • Employee Age:
    • Enter the minimum and maximum age of the employee.
  • Salary Inc. Due Basis:
    • Service – Salary increment is based on employee service period.
    • Annual – Annual increment option for employees.

Leave:

Leave, permission, and overtime details can be configured in this section.

  • Perm. Based on:
    • Uncategory – Permission applicable for all employees.
    • Category – Permission enabled for specific employees.
  • No. of Perm in a Month:
    • Defines the number of permissions allowed per month as per policy.
  • Total Perm Hrs:
    • Defines the total permission hours allowed for employees.
  • OT Based on:
    • Uncategory – Overtime applicable for all employees.
    • Category – Overtime enabled for specific employee groups.
  • Min. OT Hrs:
    • Overtime eligibility is based on this configuration and company policy.

Payroll:

  • Salary Calculation:
    • Payroll Calendar Days – Payroll is generated based on the defined payroll calendar.
    • Specific No. of Days – Fixed number of days for payroll generation.
    • Unit Based – Payroll generated for a specific unit.
    • Group Based – Payroll generated for a specific employee group.
