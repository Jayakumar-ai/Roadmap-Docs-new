The Instrument Location can be defined in this screen. This screen is used to add, modify, and delete the Instruments Location.

Navigation Path:

Quality Control \ Setup \ Setup – Quality

Instruments Location:

  • Click to create.
  • Select the Location from LOV.
  • Select the Unit.
  • Click to save.

Modify Instruments Location:

  • Only descriptions can be modified.
  • Click on the Instrument Location.
  • Change the Description.
  • Click to save.

Delete Instruments Location:

  • Click on the Delete button to delete the location.
