This screen is used to define Application journal Accounts for Application acct for Sales.

Navigation path:

Financials \ Setup \ CPC/GL account \ appl accts (sales).

Unit Wise

  • Click to add.
  • Select the Account type in list item.
  • Select Unit Loc, Unit, Item and Class Desc.
  • Enter GL Account.
  • Enter %, GST Clsf and GST Supply.
  • Enable Active Checkbox.
  • Click to save.

Stock Transaction

This tab is used to set stock transaction Account.

  • Click to add.
  • Enter/Select the Warehouse.
  • Select the Department from LOV.
  • Select the account from LOV.
  • Select the Account type in LOV.
  • Click to save.

Stock Adjustment

This Tab used to set the department wise group account for stock adjustment.

  • Click to add.
  • Select warehouse in LOV.
  • Select class Description and prefix in LOV.
  • Select account in LOV.
  • Click to save.
